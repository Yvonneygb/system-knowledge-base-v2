<KbCard num="1" title="重点逻辑1：预提数据生成与更新 {数据维护}">
<ul><li><strong>业务意义</strong>：预提数据需要定期更新，确保报表数据准确</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：通过updateAccrualData接口更新预提数据</li></ul>
<ul><li>第2点：Repository层通过queryNewWriteoffInQuotaView方法查询预提视图数据</li></ul>
<ul><li>第3点：汇总出库预提、兑现等数据生成报表</li></ul>
</KbCard>

<KbCard num="2" title="重点逻辑2：推送共享财务系统 {数据推送}">
<ul><li><strong>业务意义</strong>：预提数据推送至共享财务系统，确保财务核算同步</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：单据类型fin_fee_withholding_in_quota（额度内预提）</li></ul>
<ul><li>第2点：通过FsscApiController推送至共享财务系统</li></ul>
