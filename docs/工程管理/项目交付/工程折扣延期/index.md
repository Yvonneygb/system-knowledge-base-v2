<h4>报错1：折扣单号不能为空</h4>

<pre class="detail-sql" v-pre><code>SELECT edec.DISCOUNT_ECN_ID, edec.DISCOUNT_ECN_CODE, edec.DISCOUNT_APPLY_OBJ,

  FROM EPM_DISCOUNT_ECN edec
  WHERE edec.DISCOUNT_ECN_ID = :discountEcnId
    AND (edec.DISCOUNT_APPLY_OBJ IS NULL OR edec.DISCOUNT_APPLY_OBJ = 0)
  -- 查出折扣单号为空的延期单</code></pre>
<h4>报错2：新折扣有效期不能为空</h4>
<ul><li><strong>触发条件</strong>：保存工程折扣延期单时，新折扣有效期(DISCOUNT_VALID_DATE)为空</li><li><strong>逻辑分析</strong>：保存校验中检查DISCOUNT_VALID_DATE非空，因延期必须指定新的有效期。需选择新折扣有效期后保存</li><li><strong>排查SQL</strong>：</li></ul>
<pre class="detail-sql" v-pre><code>SELECT edec.DISCOUNT_ECN_ID, edec.DISCOUNT_ECN_CODE, edec.DISCOUNT_VALID_DATE,
         edec.SOURCE_DISCOUNT_VALID_DATE, edec.HZ_APPROVE_STATUS
  FROM EPM_DISCOUNT_ECN edec
  WHERE edec.DISCOUNT_ECN_ID = :discountEcnId
    AND edec.DISCOUNT_VALID_DATE IS NULL
  -- 查出新折扣有效期为空的延期单</code></pre>
<h4>报错3：新折扣有效期必须大于原折扣有效期</h4>
<ul><li><strong>触发条件</strong>：保存工程折扣延期单时，新折扣有效期≤原折扣有效期</li><li><strong>逻辑分析</strong>：保存校验中检查DISCOUNT_VALID_DATE&gt;SOURCE_DISCOUNT_VALID_DATE，因延期是向后延伸。需选择大于原有效期的新日期</li><li><strong>排查SQL</strong>：</li></ul>
<pre class="detail-sql" v-pre><code>SELECT edec.DISCOUNT_ECN_ID, edec.DISCOUNT_ECN_CODE, edec.SOURCE_DISCOUNT_VALID_DATE,
         edec.DISCOUNT_VALID_DATE AS 新折扣有效期
  FROM EPM_DISCOUNT_ECN edec
  WHERE edec.DISCOUNT_ECN_ID = :discountEcnId
    AND edec.DISCOUNT_VALID_DATE &lt;= edec.SOURCE_DISCOUNT_VALID_DATE
  -- 查出新有效期≤原有效期的延期单</code></pre>
<h4>报错4：延期说明不能为空</h4>

<h4>报错7：折扣单已存在延期中申请</h4>

<h4>报错8：折扣申请单ID不能为空</h4>

<pre class="detail-sql" v-pre><code>-- 接口入参校验，无对应SQL

<h4>报错11：折扣单【&#123;code&#125;】没有可延期的明细，不能延期申请</h4>
