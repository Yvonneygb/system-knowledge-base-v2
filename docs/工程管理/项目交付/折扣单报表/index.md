<div class="kl-wrap">
<KbCard num="1" title="重点逻辑1：纯报表查询页面">
<ul><li><strong>业务意义</strong>：提供折扣单数据的多维度查询和汇总展示，支撑折扣执行监控与对账</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：本页面为hlod低代码报表页面，无独立前端源码，仅提供查询和导出功能</li></ul>
<ul><li>第2点：支持按合同、客户、项目、时间等多条件查询</li></ul>
<ul><li>第3点：关联查询折扣单头、行、客户、合同、项目、出库行汇总等表</li></ul>
</KbCard>

<KbCard num="2" title="重点逻辑2：确认出库数量汇总">
<ul><li><strong>业务意义</strong>：汇总折扣单行对应的已出库数量，监控折扣单执行进度</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：关联sa_out_bill_line表，按discount_apply_line_id分组汇总SUM(confirm_out_qty)</li></ul>
<ul><li>第2点：确认出库金额=确认出库数量×折后单价</li></ul>
</KbCard>

<KbCard num="3" title="重点逻辑3：折后价格截断">
<ul><li><strong>业务意义</strong>：折后价格和金额截断到3位小数，保证数据精度一致</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：discounted_price使用trunc(discounted_price, 3)截断到3位小数</li></ul>
<ul><li>第2点：discounted_amount使用trunc(discounted_amount, 3)截断到3位小数</li></ul>
</KbCard>

<KbCard num="4" title="重点逻辑4：工程家装区分">
<ul><li><strong>业务意义</strong>：通过isHome参数区分工程和家装折扣单报表</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：isHome=0为工程折扣单报表，isHome=2为家装折扣单报表</li></ul>
<ul><li>第2点：页面固定传isHome=0</li></ul>
</KbCard>

<KbCard num="5" title="重点逻辑5：值集自动翻译">
<ul><li><strong>业务意义</strong>：值集字段自动翻译为含义文本，便于阅读</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：@ProcessLovValue注解自动翻译hzApproveStatus、contractType等值集字段</li></ul>
<ul><li>第2点：翻译结果直接展示在报表中</li></ul>
</KbCard>

         c.short_name, da.trading_company_name, ep.is_local,
         da.billing_unit_name, da.contract_code, da.contract_name,

         da.contract_type, da.is_home, da.hz_approve_status,
         epc.strategic_related, epc.contract_amt, epc.supplement_type,
         ep.project_type, epc.valid AS contract_valid, epc.signed_date,
         report.area_full_name, report.address,
         epc.contract_unit, epc.project_category,
         dal.item_code, dal.item_name, dal.model, dal.color, dal.remark,
         dal.contract_qty, dal.replaced_qty, dal.delayed_qty, dal.active_qty, dal.ordered_qty,
         dal.stand_price, dal.base_discount_rate, dal.extra_discount_rate, dal.discount_rate,
         trunc(dal.discounted_price, 3) AS discounted_price,
         trunc(dal.discounted_amount, 3) AS discounted_amount,
         sa.confirm_out_qty,
         sa.confirm_out_qty * dal.discounted_price AS confirm_out_amount
  FROM epm_discount_apply da
    JOIN customer c ON da.customer_id = c.customer_id
    LEFT JOIN epm_project_contract epc ON da.contract_id = epc.contract_id
    LEFT JOIN epm_project ep ON ep.project_id = epc.project_id
    LEFT JOIN epm_report report ON da.project_id = report.project_id
    JOIN epm_discount_apply_line dal ON da.discount_apply_id = dal.discount_apply_id
    LEFT JOIN (SELECT SUM(sl.confirm_out_qty) confirm_out_qty, sl.discount_apply_line_id
               FROM sa_out_bill_line sl
               WHERE sl.discount_apply_line_id IS NOT NULL AND sl.discount_apply_line_id &gt; 0
               GROUP BY sl.discount_apply_line_id) sa
      ON dal.discount_apply_line_id = sa.discount_apply_line_id
) WHERE is_home = 0

<h4>报错1：查询条件时间范围不能为空</h4>
<ul><li><strong>触发条件</strong>：用户点击"查询"或"导出"按钮时，申请日期起止范围(creationDateStart/creationDateEnd)未选择或为空</li><li><strong>逻辑分析</strong>：前端校验申请日期范围必填，因折扣单报表数据量大，强制按EPM_DISCOUNT_APPLY.CREATION_DATE区间过滤以避免全表扫描。该报错为toast提醒级别，不发起后端请求</li><li><strong>排查SQL</strong>：</li></ul>

<h4>报错2：导出数据量超过限制</h4>
