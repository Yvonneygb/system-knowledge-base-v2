<KbCard num="1" title="重点逻辑1：纯报表查询页面【只读查询】">
<ul><li><strong>业务意义</strong>：供内部人员查询门店验收与报销单的汇总报表信息，了解验收报销的整体情况及各维度报销金额</li><li><strong>具体逻辑描述</strong>：</li><li>本页面为hlod低代码报表页面，无独立前端源码</li><li>仅提供查询和导出功能，不支持新增、修改、删除操作</li><li>数据来源于验收报销单头表 <code>FIN_FEE_CHECK_BX_HEADER</code>，包含额度内/额度外/门头的验收标准、复核标准及可报销金额</li></ul>
</KbCard>

<KbCard num="2" title="重点逻辑2：审批节点名称动态获取">
<ul><li><strong>业务意义</strong>：根据审批状态动态展示当前审批节点名称，便于用户了解单据审批进度</li><li><strong>具体逻辑描述</strong>：</li><li>通过CASE语句处理：HZ_APPROVE_STATUS='NEW'时显示"新建"，='APPROVED'时显示"已审核"</li><li>其他状态通过LEFT JOIN <code>HZERO.HWKF_RUN_TASK_HISTORY</code> 表，取STATUS='RUN'的节点名称（NODE_NAME）</li><li>关联条件：<code>cbh.HZ_INSTANCE_ID = sp.INSTANCE_ID</code></li></ul>
</KbCard>

<KbCard num="3" title="重点逻辑3：签名状态子查询关联">
<ul><li><strong>业务意义</strong>：获取对应装修申请单的签名状态，用于判断装修申请是否已电子签名</li><li><strong>具体逻辑描述</strong>：</li><li>通过子查询从 <code>FIN_FEE_APPLY_FINISHED_HEADER</code> 表获取签名状态</li><li>SQL：<code>(SELECT afh.signature_state FROM epms.fin_fee_apply_finished_header afh WHERE afh.terminal_apply_id = cbh.terminal_apply_id)</code></li></ul>
</KbCard>

<KbCard num="4" title="重点逻辑4：免扣比例计算">
<ul><li><strong>业务意义</strong>：计算验收超期和装修超期的免扣比例合计，用于报销金额核算</li><li><strong>具体逻辑描述</strong>：</li><li><code>check_free_proportion = NVL(check_overtime_free, 0) + NVL(decoration_overtime_free, 0)</code></li><li>check_overtime_free：验收提单超期减免(%)</li><li>decoration_overtime_free：装修超期减免(%)</li></ul>
</KbCard>

<KbCard num="5" title="重点逻辑5：时间范围查询含当天">
<ul><li><strong>业务意义</strong>：结束时间查询包含当天数据，避免遗漏当天创建的单据</li><li><strong>具体逻辑描述</strong>：</li><li>创建时间范围使用 <code>to_date</code> 转换</li><li>结束日期加1天（<code>+ 1</code>）实现包含当天：<code>create_time &lt;= to_date(#&#123;endTime&#125;, 'yyyy-mm-dd') + 1</code></li></ul>
</KbCard>

<p>A：数据来源于验收报销单头表 <code>FIN_FEE_CHECK_BX_HEADER</code>，关联工作流任务历史表（HWKF_RUN_TASK_HISTORY）、交易公司表（EPM_TRADING_COMPANY）、事业部基础设置表（DIVISION_BASE_SET）获取补充信息。</p>
<p><strong>Q2：审批节点名称如何展示？</strong></p>
<p>A：通过CASE语句处理：HZ_APPROVE_STATUS='NEW'显示"新建"，='APPROVED'显示"已审核"，其他状态取工作流运行中任务节点名称（HWKF_RUN_TASK_HISTORY.NODE_NAME）。</p>
<p><strong>Q3：报表是否支持导出？</strong></p>
<p>A：是，支持导出Excel，供内部管理决策与归档使用。</p>
<p><strong>Q4：报表是否支持新增/修改/删除？</strong></p>
<p>A：不支持，本页面为纯查询报表，仅支持查看和导出。相关写操作在"门店装修-门店验收与报销单"页面进行。</p>
<p><strong>Q5：免扣比例如何计算？</strong></p>
<p>A：<code>check_free_proportion = NVL(check_overtime_free, 0) + NVL(decoration_overtime_free, 0)</code>，即验收提单超期减免(%) + 装修超期减免(%)。</p>
<p><strong>Q6：结束时间查询是否包含当天？</strong></p>
<p>A：是，SQL中结束日期加1天（<code>+ 1</code>）实现包含当天：<code>create_time &lt;= to_date(#&#123;endTime&#125;, 'yyyy-mm-dd') + 1</code>。</p>
