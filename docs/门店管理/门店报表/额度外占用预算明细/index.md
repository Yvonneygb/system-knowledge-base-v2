<KbCard num="1" title="重点逻辑1：纯报表查询页面【只读查询】">
<ul><li><strong>业务意义</strong>：供内部人员查询额度外预算的占用明细，了解预算执行情况</li><li><strong>具体逻辑描述</strong>：</li><li>本页面为hlod低代码报表页面，无独立前端源码</li><li>仅提供查询和导出功能，不支持新增、修改、删除操作</li><li>数据来源于4段UNION ALL查询，覆盖终端和大客户两类业务</li></ul>
</KbCard>

<KbCard num="2" title="重点逻辑2：4段UNION ALL统计逻辑">
<ul><li><strong>业务意义</strong>：分别统计4种不同业务场景的额度外预算占用</li><li><strong>具体逻辑描述</strong>：</li><li>第1段（终端费用申请占用）：<code>view_occupy_amt</code>视图，条件 <code>(afh_stat='APPROVED' or afh_stat='RUN') and cbh_stat='NEW'</code>，占用金额=out_apply_amt</li><li>第2段（兑付占用）：<code>view_occupy_amt</code>视图，条件 <code>cbh_stat='RUN'</code>，占用金额=out_can_bx_amt</li><li>第3段（兑付超额占用）：<code>view_occupy_amt</code>视图，条件 <code>trc_stat='APPROVED'</code>，占用金额=out_sur_bx_amt</li><li>第4段（大客户DH报销占用）：<code>CUST_DH_REIMBURSE_HEAD</code> + <code>CUST_DH_CASHOUT_HEAD</code>，条件 <code>HZ_APPROVE_STATUS IN ('RUN','APPROVED','REBUT')</code>，占用金额=报销额度外金额-已申请兑付金额</li></ul>
</KbCard>

<KbCard num="3" title="重点逻辑3：大客户DH报销占用计算">
<ul><li><strong>业务意义</strong>：计算大客户门头报销的额度外占用金额</li><li><strong>具体逻辑描述</strong>：</li><li>报销占用：<code>NVL(OUT_BX_AMT, 0) - (SELECT NVL(SUM(OUT_CASHOUT_APPLY_AMT), 0) FROM CUST_DH_CASHOUT_HEAD WHERE REIMBURSE_HEAD_ID=t.ID AND HZ_APPROVE_STATUS IN ('RUN','REBUT'))</code></li><li>即：报销额度外金额 - 已申请兑付金额（审批中或已驳回的）</li><li>跨年度兑付占用：<code>CUST_DH_CASHOUT_HEAD</code>中<code>YEAR &lt;&gt; CUST_DH_REIMBURSE_HEAD.YEAR</code>的记录，占用金额=OUT_CASHOUT_APPLY_AMT</li></ul>
</KbCard>

<KbCard num="4" title="重点逻辑4：只展示占用金额大于0的记录">
<ul><li><strong>业务意义</strong>：过滤掉占用金额为0或负数的记录，只展示实际有占用的明细</li><li><strong>具体逻辑描述</strong>：</li><li>外层统一过滤条件：<code>bod.occupy_amt &gt; 0</code></li><li>确保报表只展示有实际预算占用的记录</li></ul>
</KbCard>

<KbCard num="5" title="重点逻辑5：查询条件匹配规则">
<ul><li><strong>业务意义</strong>：支持多维度灵活筛选额度外占用预算明细</li><li><strong>具体逻辑描述</strong>：</li><li>精确查询：预算年度、门店编码、经销商编码、开票单位编码、交易公司编码</li><li>事业部ID通过子查询转换：<code>bod.division_id = (SELECT dbs.division_id FROM division_base_set dbs WHERE dbs.organization_id = #&#123;divisionId&#125;)</code></li><li>注意：DTO中organizationId字段在SQL中未使用</li></ul>
</KbCard>

```sql
-- 额度外占用预算明细查询（4段UNION ALL）
SELECT * FROM (
    -- 第1段：终端费用申请占用
    SELECT voa.out_apply_amt AS occupy_amt, voa.bud_year, voa.afh_audit_stat AS audit_stat,
           voa.terminal_apply_no AS apply_code, voa.afh_create_time AS apply_time,
           voa.terminal_code, voa.terminal_name, voa.cust_code, voa.cust_name,
           voa.billing_unit_code, voa.billing_unit_name, voa.trading_company_code, voa.trading_company_name,
           voa.division_id, voa.division_name
    FROM epms.view_occupy_amt voa
    WHERE (voa.afh_stat = 'APPROVED' OR voa.afh_stat = 'RUN') AND (voa.cbh_stat = 'NEW')

    UNION ALL
    -- 第2段：兑付占用
    SELECT voa.out_can_bx_amt AS occupy_amt, voa.bud_year, voa.cbh_audit_stat AS audit_stat,
           voa.check_bx_code AS apply_code, voa.cbh_create_time AS apply_time,
           voa.terminal_code, voa.terminal_name, voa.cust_code, voa.cust_name,
           voa.billing_unit_code, voa.billing_unit_name, voa.trading_company_code, voa.trading_company_name,
           voa.division_id, voa.division_name
    FROM epms.view_occupy_amt voa
    WHERE voa.cbh_stat = 'RUN'

    UNION ALL
    -- 第3段：兑付超额占用
    SELECT voa.out_sur_bx_amt AS occupy_amt, voa.bud_year, voa.trc_audit_stat AS audit_stat,
           voa.terminal_cashout_code AS apply_code, voa.trc_create_time AS apply_time,
           voa.terminal_code, voa.terminal_name, voa.cust_code, voa.cust_name,
           voa.billing_unit_code, voa.billing_unit_name, voa.trading_company_code, voa.trading_company_name,
           voa.division_id, voa.division_name
    FROM epms.view_occupy_amt voa
    WHERE voa.trc_stat = 'APPROVED'

    UNION ALL
    -- 第4段：大客户DH报销占用
    SELECT dh_occupy.occupy_amt, dh_occupy.bud_year, dh_occupy.audit_stat, dh_occupy.apply_code, dh_occupy.apply_time,
           NULL AS terminal_code, NULL AS terminal_name,
           cus.CUSTOMER_CODE AS cust_code, cus.CUSTOMER_NAME AS cust_name,
           cus_legal.LEGAL_ENTITY_CODE AS billing_unit_code, cus_legal.LEGAL_ENTITY_NAME AS billing_unit_name,
           company.TRADING_COMPANY_CODE AS trading_company_code, cus_legal.trading_company_name AS trading_company_name,
           ent.division_id, ent.DIVISION_NAME AS division_name
    FROM (
        -- 大客户报销占用
        SELECT NVL(t.OUT_BX_AMT, 0) - (
            SELECT NVL(SUM(OUT_CASHOUT_APPLY_AMT), 0) FROM epms.CUST_DH_CASHOUT_HEAD cashout
            WHERE cashout.REIMBURSE_HEAD_ID = t.ID AND cashout.HZ_APPROVE_STATUS IN ('RUN','REBUT')
        ) AS occupy_amt,
        to_char(t.YEAR) AS bud_year, t.AUDIT_STAT AS audit_stat, t.REIMBURSE_CODE AS apply_code, t.CREATED AS apply_time,
        t.CUSTOMER_ID AS customer_id, t.CUSTOMER_LEGAL_ID AS customer_legal_id, t.ENTID AS entid
        FROM epms.CUST_DH_REIMBURSE_HEAD t
        WHERE t.HZ_APPROVE_STATUS IN ('RUN','APPROVED','REBUT')

        UNION ALL
        -- 跨年度兑付占用
        SELECT NVL(t.OUT_CASHOUT_APPLY_AMT, 0) AS occupy_amt,
        to_char(t.YEAR) AS bud_year, t.AUDIT_STAT AS audit_stat, t.CASHOUT_NO AS apply_code, t.CREATED AS apply_time,
        t.CUSTOMER_ID AS customer_id, t.CUSTOMER_LEGAL_ID AS customer_legal_id, t.ENTID AS division_id
        FROM epms.CUST_DH_CASHOUT_HEAD t
        LEFT JOIN epms.CUST_DH_REIMBURSE_HEAD t2 ON t.REIMBURSE_HEAD_ID = t2.ID
        WHERE t.HZ_APPROVE_STATUS IN ('RUN','REBUT') AND t.YEAR <> t2.YEAR
    ) dh_occupy
    LEFT JOIN epms.CUSTOMER cus ON cus.CUSTOMER_ID = dh_occupy.customer_id
    LEFT JOIN epms.CUSTOMER_LEGAL_ENTITY cus_legal ON cus_legal.REL_ID = dh_occupy.customer_legal_id
    LEFT JOIN epms.DIVISION_BASE_SET ent ON dh_occupy.entid = ent.ORGANIZATION_ID
    LEFT JOIN epms.EPM_TRADING_COMPANY company ON cus_legal.TRADING_COMPANY_ID = company.TRADING_COMPANY_ID
) bod
WHERE bod.occupy_amt > 0                                       -- 只展示占用金额>0的记录
    AND bod.division_id = (SELECT dbs.division_id FROM division_base_set dbs WHERE dbs.organization_id = #{divisionId})  -- 事业部ID
    AND bod.bud_year = #{budYear}                              -- 预算年度（精确）
    AND bod.terminal_code = #{terminalCode}                    -- 门店编码（精确）
    AND bod.cust_code = #{custCode}                            -- 经销商编码（精确）
    AND bod.billing_unit_code = #{billingUnitCode}             -- 开票单位编码（精确）
    AND bod.trading_company_code = #{tradingCompanyCode}       -- 交易公司编码（精确）
```

    <div class="detail-text" v-pre><strong>触发条件：</strong>点击"查询"按钮，按当前查询条件（事业部、预算年度、门店编码、经销商编码、开票单位编码、交易公司编码等）查询4段UNION ALL返回空结果集<br><strong>逻辑分析：</strong>报表通过4段UNION ALL分别统计终端费用申请占用（VIEW_OCCUPY_AMT，afh_stat=APPROVED/RUN且cbh_stat=NEW）、兑付占用（cbh_stat=RUN）、兑付超额占用（trc_stat=APPROVED）、大客户DH报销占用（CUST_DH_REIMBURSE_HEAD+CUST_DH_CASHOUT_HEAD，HZ_APPROVE_STATUS IN RUN/APPROVED/REBUT），外层过滤occupy_amt&gt;0。若查询条件过严、或所有占用金额&lt;=0被过滤、或预算年度下无占用记录、或事业部ID通过子查询转换失败（DIVISION_BASE_SET无匹配），均会返回空结果。该报错为提示性。</div>
      <h5>排查SQL</h5>
    <pre class="detail-sql language-sql" v-pre><code>SELECT bud_year            AS 预算年度,
         division_id         AS 事业部ID,
         occupy_amt          AS 占用金额,
         apply_code          AS 申请单号,
         cust_code           AS 经销商编码
  FROM   view_occupy_amt
  WHERE  occupy_amt &gt; 0
  ORDER  BY bud_year DESC;
--</code></pre></div>

    <h4><span style="color:#7C3AED;">报错：</span>大客户DH报销占用计算异常</h4>
    <h5>详细逻辑</h5>
    <div class="detail-text" v-pre><strong>触发条件：</strong>查询结果展示时，CUST_DH_CASHOUT_HEAD中存在REIMBURSE_HEAD_ID关联不到CUST_DH_REIMBURSE_HEAD的记录，LEFT JOIN导致t2.YEAR为NULL<br><strong>逻辑分析：</strong>第4段UNION ALL计算大客户DH报销占用时，通过LEFT JOIN CUST_DH_CASHOUT_HEAD关联CUST_DH_REIMBURSE_HEAD，并计算跨年度兑付占用（<code>t.YEAR &lt;&gt; t2.YEAR</code>）。若CUST_DH_CASHOUT_HEAD.REIMBURSE_HEAD_ID指向已删除的报销单（孤儿数据）、或REIMBURSE_HEAD_ID字段值错误、或数据迁移产生脏数据，LEFT JOIN后t2（报销单）字段为NULL，<code>t.YEAR &lt;&gt; t2.YEAR</code>条件中NULL参与比较结果为UNKNOWN，导致跨年度兑付占用金额计算错误（漏统计或错统计），报表数据异常。</div>
      <h5>排查SQL</h5>
    <pre class="detail-sql language-sql" v-pre><code>SELECT c.cashout_no            AS 兑付单号,
         c.reimburse_head_id     AS 关联报销单ID,
         c.year                  AS 兑付年度,
         c.out_cashout_apply_amt AS 额度外兑付申请金额,
         c.hz_approve_status     AS 审批状态
  FROM   cust_dh_cashout_head c
  LEFT   JOIN cust_dh_reimburse_head t ON c.reimburse_head_id = t.id
  WHERE  c.reimburse_head_id IS NOT NULL
  AND    t.id IS NULL
  ORDER  BY c.created DESC;
--</code></pre></div>
