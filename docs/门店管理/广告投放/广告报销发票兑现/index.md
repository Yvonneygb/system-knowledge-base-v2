<div class="kl-wrap">
<KbCard num="1" title="重点逻辑1：额度内与额度外兑现区分 {兑现类型}">
<ul><li><strong>业务意义</strong>：兑现分为额度内和额度外，校验和预算处理逻辑不同</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：cashoutType=1为额度内，校验本次核销金额不超过额度内可用金额</li></ul>
<ul><li>第2点：cashoutType=2为额度外，校验本次兑现金额不超过额度外可用金额-已占用金额</li></ul>
<ul><li>第3点：额度外审批通过后更新额度外预算已使用金额，按月份区分当年/次年</li></ul>
</KbCard>

<KbCard num="2" title="重点逻辑2：兑现金额校验 {核心校验}">
<ul><li><strong>业务意义</strong>：确保兑现金额不超过剩余可兑现金额</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：本次兑现金额&lt;=可兑现总额-已兑现总额</li></ul>
<ul><li>第2点：支付方式非3（非虚拟收款）时，发票金额必须&gt;0</li></ul>
<ul><li>第3点：提交时校验申请兑现金额不超过剩余未兑现总额</li></ul>
</KbCard>

<KbCard num="3" title="重点逻辑3：ERP资金池同步 {ERP集成}">
<ul><li><strong>业务意义</strong>：审批通过后同步资金池调整到ERP</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：组装资金池数据（源单据ID、交易公司、客户、金额等）</li></ul>

    <div class="detail-text" v-pre><strong>触发条件：</strong>电子签章校验时，按兑现单ID查询工作流流程信息返回null<br><strong>逻辑分析：</strong>电子签章需关联工作流实例。若兑现单未发起工作流（HZ_INSTANCE_ID为空）、工作流实例已被清理、或兑现单已被删除，查询流程信息返回空，签章校验失败。常见根因：单据未提交即触发签章、工作流实例过期、或单据ID传值错误。</div>
      <h5>排查SQL</h5>
    <pre class="detail-sql language-sql" v-pre><code>SELECT fee_cashout_id      AS 兑现单ID,
         fee_cashout_no      AS 兑现单号,
         hz_instance_id      AS 工作流实例ID,
         hz_approve_status   AS 审批状态,
         signature_state     AS 签章状态
  FROM   fin_fee_cashout_header
  WHERE  save_type = 2
  AND    (hz_instance_id IS NULL OR hz_approve_status = 'NEW')
  ORDER  BY create_time DESC;</code></pre></div>
</div>


<div id="err-detail-10" class="error-detail-overlay">
  <div class="error-detail-box" v-pre>
    <a href="#" class="close-btn">&times;</a>
    <h4><span style="color:#7C3AED;">报错：</span>门店编码或预算年度不能为空</h4>
    <h5>详细逻辑</h5>
    <div class="detail-text" v-pre><strong>触发条件：</strong>额度外兑现审批通过后更新额度外预算时，门店编码TERMINAL_CODE或预算年度BUD_YEAR为空<br><strong>逻辑分析：</strong>额度外预算更新需用门店编码和预算年度定位MKT_OUTLIMIT_BUD_HEADER记录。若报销单未带入门店编码、预算年度未填写，或字段在流转中丢失，后端校验为空即抛异常，无法更新预算已使用金额。</div>
      <h5>排查SQL</h5>
    <pre class="detail-sql language-sql" v-pre><code>SELECT fee_cashout_id      AS 兑现单ID,
         fee_cashout_no      AS 兑现单号,
         terminal_code       AS 门店编码,
         bud_year            AS 预算年度,
         cashout_type        AS 兑现类型
  FROM   fin_fee_cashout_header
  WHERE  save_type = 2
  AND    cashout_type = 2
  AND    (terminal_code IS NULL OR bud_year IS NULL)
  ORDER  BY create_time DESC;</code></pre></div>
</div>


<div id="err-detail-11" class="error-detail-overlay">
  <div class="error-detail-box" v-pre>
    <a href="#" class="close-btn">&times;</a>
    <h4><span style="color:#7C3AED;">报错：</span>可兑现总额不能为零或负数</h4>
    <h5>详细逻辑</h5>
    <div class="detail-text" v-pre><strong>触发条件：</strong>额度外预算更新时，读取报销单可兑现总额TOTAL_CAN_CASHOUT_AMT&lt;=0<br><strong>逻辑分析：</strong>额度外预算更新需用可兑现总额计算使用金额（使用金额=本次申请金额×兑现比例÷税率）。若可兑现总额为0或负数，计算结果异常，抛异常终止预算更新。常见根因：报销单可兑现总额被错误置0、数据迁移错误、或报销单本身金额异常。</div>
      <h5>排查SQL</h5>
    <pre class="detail-sql language-sql" v-pre><code>SELECT fee_cashout_id      AS 兑现单ID,
         fee_cashout_no      AS 兑现单号,
         total_can_cashout_amt AS 可兑现总额,
         used_cashout_amt    AS 已兑现总额,
         cashout_type        AS 兑现类型
  FROM   fin_fee_cashout_header
  WHERE  save_type = 2
  AND    cashout_type = 2
  AND    (total_can_cashout_amt IS NULL OR total_can_cashout_amt &lt;= 0)
  ORDER  BY create_time DESC;</code></pre></div>
</div>

    <h4><span style="color:#7C3AED;">报错：</span>税率配置格式错误</h4>
    <h5>详细逻辑</h5>
    <div class="detail-text" v-pre><strong>触发条件：</strong>额度外预算更新时，读取系统配置SCPSYSCONF中Outlimit_Tax_Rate的值格式错误（非数字或为空）<br><strong>逻辑分析：</strong>额度外预算使用金额需除以税率（使用金额=本次申请金额×兑现比例÷税率）。税率从系统配置Outlimit_Tax_Rate读取，若配置缺失、值为非数字字符串、或为0（除零异常），抛异常终止预算更新。常见根因：运维未配置Outlimit_Tax_Rate、配置值被误改、或格式不规范。</div>
      <h5>排查SQL</h5>
    <pre class="detail-sql language-sql" v-pre><code>SELECT confname            AS 配置名称,
         confvalue           AS 配置值
  FROM   scpsysconf
  WHERE  confname = 'Outlimit_Tax_Rate';</code></pre></div>

    <a href="#" class="close-btn">&times;</a>
    <h4><span style="color:#7C3AED;">报错：</span>额度外预算数据不存在，请检查！</h4>
    <h5>详细逻辑</h5>
    <div class="detail-text" v-pre><strong>触发条件：</strong>额度外兑现审批通过后更新预算时，按门店编码+预算年度查询MKT_OUTLIMIT_BUD_HEADER返回null<br><strong>逻辑分析：</strong>额度外预算更新需定位预算头表记录。若该门店该年度未配置额度外预算、预算已被删除、或门店编码与预算年度不匹配，查询返回空，无法更新已使用金额，抛异常。常见根因：预算未配置、门店未纳入预算范围、或预算年度错误。</div>
      <h5>排查SQL</h5>
    <pre class="detail-sql language-sql" v-pre><code>SELECT c.fee_cashout_id      AS 兑现单ID,
         c.fee_cashout_no      AS 兑现单号,
         c.terminal_code       AS 门店编码,
         c.bud_year            AS 预算年度,
         b.terminal_code       AS 预算门店编码
  FROM   fin_fee_cashout_header c
  LEFT   JOIN mkt_outlimit_bud_header b
         ON b.terminal_code = c.terminal_code
        AND b.bud_year = c.bud_year
  WHERE  c.save_type = 2
  AND    c.cashout_type = 2
  AND    b.terminal_code IS NULL
  ORDER  BY c.create_time DESC;</code></pre></div>
