<div class="kl-wrap">
<KbCard num="1" title="重点逻辑1：额度内与额度外区分 {费用类型}">
<ul><li><strong>业务意义</strong>：广告投放申请分为额度内和额度外两种，预算控制逻辑不同</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：bxType=1为额度内，使用年度资源额度内的可用金额</li></ul>
<ul><li>第2点：bxType=2为额度外，审批通过时扣减BUD_OVER_BUDGET预算表，驳回时加回</li></ul>
<ul><li>第3点：额度外可用余额=可用金额-占用金额</li></ul>
</KbCard>

<KbCard num="2" title="重点逻辑2：OA审批集成 {OA集成}">
<ul><li><strong>业务意义</strong>：广告投放申请走OA审批流程，需推送数据到OA并处理回调</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：提交时组装广告投放数据（申请单号、广告项目、媒介类型等）推送到OA系统</li></ul>
<ul><li>第2点：OA审批通过回调时，更新可用金额、申请总金额、审批总金额、使用占比等字段</li></ul>
<ul><li>第3点：OA审批驳回回调时，额度外需加回已扣减的预算金额</li></ul>
<ul><li>第4点：通过callbackSource变量(1=通过/2=驳回)驱动工作流分支</li></ul>
</KbCard>

<KbCard num="3" title="重点逻辑3：申请使用占比计算 {金额计算}">
<ul><li><strong>业务意义</strong>：自动计算申请使用占比和批准使用占比</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：申请使用占比=申请总金额/可用金额（保留6位小数）</li></ul>

</KbCard>

<h4>报错1：申请总金额必须大于0！</h4>
<ul><li><strong>触发条件</strong>：点击"提交"按钮，OA推送前调用doCheckAdvertiseAmt校验时，totalApplyAmtBx&lt;=0</li><li><strong>逻辑分析</strong>：提交审批前需确保申请总金额有效。校验逻辑读取FIN_FEE_APPLY_HEADER.TOTAL_APPLY_AMT_BX，若该值&lt;=0则抛出阻断性异常，阻止OA推送和工作流发起。常见根因：用户未填写金额、金额被错误置0、或前端未做必填校验直接提交空单。</li><li><strong>排查SQL</strong>：</li></ul>

```sql
SELECT fee_apply_id        AS 申请单ID,
         fee_apply_no        AS 申请单号,
         total_apply_amt_bx  AS 申请总金额,
         hz_approve_status   AS 审批状态
  FROM   fin_fee_apply_header
  WHERE  apply_type = 2
  AND    total_apply_amt_bx <= 0
  ORDER  BY create_time DESC;
```
<h4>报错2：流程中objid为0，流程失败！</h4>
