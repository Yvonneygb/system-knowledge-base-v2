<KbCard num="1" title="重点逻辑1：模板类型驱动显隐">
<ul><li><strong>业务意义</strong>：不同模板类型需要配置不同字段，动态显隐减少无效字段干扰</li><li><strong>具体逻辑描述</strong>：模板类型决定页面字段显隐，授权书类型显示更换授权单位勾选框与授权单位下拉；经销合同/装修协议/广告协议类型显示模板子类型；授权书/承诺函类型显示模板变量表格</li></ul>
</KbCard>

<KbCard num="2" title="重点逻辑2：模板子类型动态值集">
<ul><li><strong>业务意义</strong>：子类型选项随模板类型变化，确保选项与类型匹配</li><li><strong>具体逻辑描述</strong>：模板子类型的 lookupCode 根据模板类型动态切换：经销合同→MBO.CONTRACT_SUB_TEMPLATE，装修协议→MBO.HARDWARE_SUB_TYPE，广告协议→MBO.ADVERTISING_SUB_TYPE</li></ul>
</KbCard>

<KbCard num="3" title="重点逻辑3：文件上传校验">
<ul><li><strong>业务意义</strong>：确保模板文件格式和大小符合要求</li><li><strong>具体逻辑描述</strong>：单个文件不超过30MB，仅支持 doc/docx 格式，上传成功后将 fileUrl/createUserName/fileType 写入附件DataSet，上传失败时弹出错误提示</li></ul>
</KbCard>

<KbCard num="4" title="重点逻辑4：变量维护">
<ul><li><strong>业务意义</strong>：模板变量用于合同生成时替换占位符</li><li><strong>具体逻辑描述</strong>：模板变量表格可动态增删行，每行包含模板中变量和模板中变量名称两个字段，均必填，提交时通过 varReqDtoList 传给后端</li></ul>
</KbCard>

<KbCard num="5" title="重点逻辑5：提交校验顺序">
<ul><li><strong>业务意义</strong>：确保提交数据完整性，按顺序校验避免遗漏</li><li><strong>具体逻辑描述</strong>：先校验基础表单 baseFormDS.validate()，再校验变量表 variableTableDS.validate()，最后校验模板文件是否已上传，任一不通过则中断提交</li></ul>
</KbCard>

<h4>按钮1：确认（详情页头部按钮，新增/编辑模式）</h4>
<p>新增/编辑模式显示"确认"按钮，调用 <code>handleSubmit</code>：</p>
<ol><li><code>baseFormDS.validate()</code> 校验基础表单（模板名称、模板类型、模板子类型、授权单位等必填字段）</li><li><code>variableTableDS.validate()</code> 校验模板变量表格（每行变量名、变量名称非空）</li><li>校验 <code>templateFile?.fileUrl</code> 是否存在，若为空则提示"请上传合同模板文件"</li><li>组装数据：<code>&#123; ...baseFormDS.current.toData(), varReqDtoList: templateVariableList, fileDTO: templateFile &#125;</code></li><li>调用 <code>contractTemplateApi.add</code>（POST <code>ch/contract/template/add</code>）或 <code>contractTemplateApi.edit</code>（POST <code>ch/contract/template/edit</code>）接口</li><li>成功后关闭当前Tab</li></ol>

```sql
SELECT T.ELECTRONIC_CONTRACT_TEMPLATE_CODE AS "模板编码",
       T.ELECTRONIC_CONTRACT_TEMPLATE_NAME AS "模板名称",
       T.TEMPLATE_TYPE                     AS "模板类型",
       T.TEMPLATE_SUBTYPE                  AS "子模板类型",
       T.AUTHORIZED_COMPANY                AS "关联公司",
       T.TEMPLATE_STATUS                   AS "状态",
       T.CREATION_DATE                     AS "创建时间",
       T.LAST_UPDATE_DATE                  AS "更新时间"
FROM ELECTRONIC_CONTRACT_TEMPLATE T
WHERE (:templateName IS NULL OR T.ELECTRONIC_CONTRACT_TEMPLATE_NAME LIKE '%' || :templateName || '%')
  AND (:templateCode IS NULL OR T.ELECTRONIC_CONTRACT_TEMPLATE_CODE LIKE '%' || :templateCode || '%')
  AND (:templateType IS NULL OR T.TEMPLATE_TYPE = :templateType)
  AND (:templateSubtype IS NULL OR T.TEMPLATE_SUBTYPE = :templateSubtype)
  AND (:templateStatus IS NULL OR T.TEMPLATE_STATUS = :templateStatus)
ORDER BY T.CREATION_DATE DESC;
```
