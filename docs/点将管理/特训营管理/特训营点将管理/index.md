<ul><li><strong>业务意义</strong>：保证申请编码唯一性，便于全链路追溯。</li><li><strong>具体逻辑描述</strong>：</li><li>提交申请时系统自动生成唯一编码 <code>applyCode</code>。</li><li>编码作为主键贯穿申请、审批、执行、取消全流程。</li></ul>
</KbCard>

<KbCard num="3" title="重点逻辑3：状态联动">
<ul><li><strong>业务意义</strong>：点将申请状态与审批状态联动，确保状态机自动推进。</li><li><strong>具体逻辑描述</strong>：</li><li>点将申请状态与审批状态联动。</li><li>审批通过后申请状态自动变更为已通过。</li><li>取消审批通过后状态变为已取消。</li></ul>
</KbCard>

<KbCard num="4" title="重点逻辑4：取消约束">
<ul><li><strong>业务意义</strong>：限制取消时机，避免随意取消造成资源浪费。</li><li><strong>具体逻辑描述</strong>：</li><li>仅已审批通过且未完成执行的申请可发起取消申请。</li><li>已生效的点将不能直接删除，只能发起取消申请。</li><li>取消审批通过后状态才变为已取消。</li></ul>
</KbCard>

<KbCard num="5" title="重点逻辑5：pageType页面类型切换">
<ul><li><strong>业务意义</strong>：通过单一页面支撑管理、审批多视图，减少重复开发。</li><li><strong>具体逻辑描述</strong>：</li><li>通过 <code>useAuthPageOption</code> 实现模式切换。</li><li><strong>manage（管理视图）</strong>：显示同步CRM、特殊取消按钮。</li><li><strong>approval（审批视图）</strong>：显示审批、同步OA、同步FDD按钮。</li><li>查询接口 <code>pageType</code> 参数默认为 <code>manage</code>。</li></ul>
</KbCard>

<KbCard num="6" title="重点逻辑6：特殊取消校验">
<ul><li><strong>业务意义</strong>：限制取消时机，避免临近开课取消造成资源浪费。</li><li><strong>具体逻辑描述</strong>：</li><li>计算时间差值 <code>timeDiff = (planStartTime - nowTime) / (24*60*60*1000)</code>。</li><li>校验条件 <code>1 &lt;= timeDiff &lt;= 7</code>（培训开始前1-7天内）。</li><li>校验审批状态 <code>approvalState === 'fdd_sign'</code>（已法大大签约）。</li><li>校验是否已发起取消：<code>cancelApprovalState</code> 不为空且不等于 <code>reject</code> 和 <code>oa_reject</code> 时提示"该单据已发起取消申请，不可重复发起！"。</li><li>校验不通过提示"只有在培训开始前七天内且已生效的单据才可以发起取消申请！"。</li><li>提交调用 <code>POST mlt/trainCampApply/cancelApply</code> 接口。</li></ul>
</KbCard>

<KbCard num="7" title="重点逻辑7：审批流程">
<ul><li><strong>业务意义</strong>：通过审批把关名额与费用，审批通过才占用资源。</li><li><strong>具体逻辑描述</strong>：</li><li>审批弹窗根据 pageType 区分。</li><li><strong>approval</strong>：申请审批，调用 <code>applyApproval</code> 接口，<code>applyTypeTwo=apply</code>，显示签订人选择。</li><li>审批参数：<code>applyTypeOne=camp</code>，<code>approvalResult=approved/reject</code>。</li><li>审批人、审批时间自动填充。</li><li>签订人 approval 时显示，审批意见必填。</li></ul>
</KbCard>

<KbCard num="8" title="重点逻辑8：查看协议书">
<ul><li><strong>业务意义</strong>：在线查看法大大协议书，便于核对签约内容。</li><li><strong>具体逻辑描述</strong>：</li><li>点击行"查看协议书"按钮，调用 <code>queryPDF</code> 接口。</li><li>参数：<code>applyCode</code>、<code>applyTypeOne=camp</code>、<code>applyTypeTwo=apply</code>。</li><li>成功后 <code>window.open</code> 打开PDF。</li></ul>
</KbCard>

<KbCard num="9" title="重点逻辑9：同步外部系统">
<ul><li><strong>业务意义</strong>：将点将数据同步至外部系统，保证多方数据一致。</li><li><strong>具体逻辑描述</strong>：</li><li><strong>同步CRM</strong>：仅 <code>pageType=manage</code> 显示，<code>POST mlt/trainCampApply/pushCrm/&#123;applyCode&#125;</code>。</li><li><strong>同步OA</strong>：<code>pageType=approval</code> 显示，<code>POST mlt/trainCampApply/pushOa/&#123;applyCode&#125;</code>。</li><li><strong>同步FDD</strong>：仅 <code>pageType=approval</code> 显示，<code>POST mlt/trainCampApply/pushFdd/&#123;applyCode&#125;</code>。</li></ul>
</KbCard>

<h5>按钮1：查看申请（列表页Header）</h5>
<ul><li><strong>业务逻辑</strong>：校验选中一条数据，openTab 新标签页跳转特训营点将详情页，路径 <code>/general/specialTrainingCamp/campGeneral/detail/&#123;applyCode&#125;/view</code>。</li><li><strong>调用接口</strong>：无。</li></ul>
<h5>按钮2：同步CRM（列表页Header）</h5>
<ul><li><strong>业务逻辑</strong>：校验选中一条数据，调用 <code>pushCrm</code> 接口推送CRM订单，成功后刷新列表。</li><li><strong>调用接口</strong>：<code>POST mlt/trainCampApply/sendCrmOrder/&#123;applyCode&#125;</code>。</li></ul>
<h5>按钮3：特殊取消（列表页Header）</h5>
<ul><li><strong>业务逻辑</strong>：校验选中一条数据，计算时间差值 <code>timeDiff = (planStartTime - nowTime) / (24*60*60*1000)</code>，校验 <code>1 &lt;= timeDiff &lt;= 7</code> 且 <code>approvalState === 'fdd_sign'</code>，校验未重复发起取消（<code>cancelApprovalState</code> 为空或为 <code>reject</code>/<code>oa_reject</code>），弹窗填写取消原因（必填），提交 <code>cancelApply</code> 接口。</li><li><strong>调用接口</strong>：<code>POST mlt/trainCampApply/cancelApply</code>。</li></ul>
<h5>按钮4：审批（列表页Header）</h5>

<KbCard title="保存校验">
<ul><li>校验1：特殊取消原因必填 —— 确保取消留痕可追溯</li><li><strong>详细逻辑</strong>：<code>cancelApplyFormDS.validate()</code> 校验取消原因必填。</li><li><strong>系统体现</strong>：前端表单校验，后端二次校验。</li><li><strong>排查SQL</strong>：</li></ul>
<pre class="detail-sql" v-pre><code>SELECT tca.APPLY_CODE AS 申请编码, tca.CANCEL_REASON AS 取消原因
    FROM TRAIN_CAMP_APPLY tca
    WHERE tca.CANCEL_APPROVAL_STATE IS NOT NULL
      AND tca.CANCEL_REASON IS NULL;</code></pre>
</KbCard>

<KbCard title="提交校验">
<ul><li>校验1：审批意见必填 —— 确保审批留痕完整</li><li><strong>详细逻辑</strong>：<code>applyApprovalFormDS.validate()</code> 校验审批意见必填，通过时签订人必填。</li><li><strong>系统体现</strong>：前端表单校验，后端二次校验。</li><li><strong>排查SQL</strong>：</li></ul>
<pre class="detail-sql" v-pre><code>SELECT tca.APPLY_CODE AS 申请编码, tca.APPROVAL_COMMENTS AS 审批意见,
           tca.SIGNER_NAME AS 签订人
    FROM TRAIN_CAMP_APPLY tca
    WHERE tca.APPROVAL_STATE = 'approved'
      AND (tca.APPROVAL_COMMENTS IS NULL OR tca.SIGNER_NAME IS NULL);</code></pre>
<ul><li>校验2：特殊取消时机校验 —— 防止临近开课取消造成资源浪费</li><li><strong>详细逻辑</strong>：校验 <code>1 &lt;= timeDiff &lt;= 7</code> 且 <code>approvalState === 'fdd_sign'</code> 且未重复发起取消。</li><li><strong>系统体现</strong>：前端时间差值计算与状态校验，后端二次校验。</li><li><strong>排查SQL</strong>：</li></ul>
<pre class="detail-sql" v-pre><code>SELECT tca.APPLY_CODE AS 申请编码, tca.CAMP_NAME AS 特训营名称,
           TO_CHAR(tca.PLAN_START_TIME, 'YYYY-MM-DD') AS 开始时间,
           tca.APPROVAL_STATE AS 审核状态,
           ROUND(tca.PLAN_START_TIME - SYSDATE) AS 距开始天数
    FROM TRAIN_CAMP_APPLY tca
    WHERE tca.APPROVAL_STATE = 'fdd_sign'
      AND tca.PLAN_START_TIME &gt; SYSDATE
      AND tca.PLAN_START_TIME &lt;= SYSDATE + 7
      AND (tca.CANCEL_APPROVAL_STATE IS NULL
           OR tca.CANCEL_APPROVAL_STATE IN ('reject', 'oa_reject'));</code></pre>
</KbCard>

<h4>报错1：请选择一条数据</h4>
<ul><li><strong>触发条件</strong>：点击查看申请、审批、同步CRM、特殊取消、同步OA、同步FDD等行操作按钮时，未选择数据或选择了多行</li><li><strong>逻辑分析</strong>：前端在执行单选操作前校验选中行数量，若 selectedRows.length ≠ 1 则阻止操作并提示"请选择一条数据"。单选操作需要明确的目标申请，未选择时无法确定操作对象，多选时操作对象不唯一</li><li><strong>排查SQL</strong>：</li></ul>

<h4>报错2：只有在培训开始前七天内且已生效的单据才可以发起取消申请！</h4>
<ul><li><strong>触发条件</strong>：点击特殊取消按钮时，不满足"培训开始前1-7天内且已法大大签约"条件</li><li><strong>逻辑分析</strong>：前端执行多重校验：①计算时间差值 timeDiff = (PLAN_START_TIME - nowTime) / (24*60*60*1000)，校验 1 &lt;= timeDiff &lt;= 7（特训营开始前1-7天内）；②校验 APPROVAL_STATE = 'fdd_sign'（已法大大签约生效）。任一校验不通过则提示"只有在培训开始前七天内且已生效的单据才可以发起取消申请！"。此校验限制取消时机，避免临近开课取消造成资源浪费，同时要求单据已生效具备业务合法性</li><li><strong>排查SQL</strong>：</li></ul>

<h4>报错8：权限不足</h4>
