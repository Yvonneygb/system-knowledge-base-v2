<KbCard num="1" title="重点逻辑1：pageType切换管理/审批视图">
<ul><li><strong>业务意义</strong>：同一页面支持管理和审批两种视图，通过 pageType 参数切换，减少页面数量</li><li><strong>具体逻辑描述</strong>：pageType=manage 为管理视图，pageType=approval 为审批视图，审批按钮仅在 pageType 不等于 manage 时显示</li></ul>
</KbCard>

<KbCard num="2" title="重点逻辑2：审批接口分流">
<ul><li><strong>业务意义</strong>：不同审批场景调用不同审批接口，确保审批流程正确流转</li><li><strong>具体逻辑描述</strong>：根据 pageType 调用不同审批接口：approval 调用 designApplyApproval，cancelApproval 调用 cancelApplyApproval，designerApproval 调用 designApplyLecturerApproval，designerCancelApproval 调用 cancelApplyApproval</li></ul>
</KbCard>

<KbCard num="3" title="重点逻辑3：项目终止审批">
<ul><li><strong>业务意义</strong>：终止申请需独立审批流程，确保终止决策有审批留痕</li><li><strong>具体逻辑描述</strong>：当 applyType=termination 且 terminationApprovalState=to_be_approval 时，走项目终止审批逻辑，调用 designApplyTerminalApproval 接口</li></ul>
</KbCard>

<KbCard num="4" title="重点逻辑4：设计改派">
<ul><li><strong>业务意义</strong>：管理视图下可更换设计师，灵活调整服务资源</li><li><strong>具体逻辑描述</strong>：仅 manage 模式可用，通过弹窗选择新设计师后调用 designReassignment 接口</li></ul>
</KbCard>

<KbCard num="5" title="重点逻辑5：多级审批链路">
<ul><li><strong>业务意义</strong>：设计点将涉及多级审批，按顺序依次触发，确保各环节确认</li><li><strong>具体逻辑描述</strong>：设计点将涉及4个内置审批流程：designApplyLecturerApproval(讲师审批)→designApplyTerminalApproval(门店审批)→designApplyApproval(常规审批)；取消审批走 designApplyCancelApproval</li></ul>

```sql
SELECT MLA.APPLY_CODE              AS "申请编码",
       MLA.APPLY_USER_NAME         AS "申请人",
       MLA.APPLY_TYPE              AS "申请类型",
       MLA.STORE_NAME              AS "门店名称",
       MLA.CREATE_DATE             AS "申请时间",
       MLA.LECTURER_NAME           AS "设计师",
       MLA.ORDER_LECTURE_STATE     AS "点将状态",
       MLA.DESIGN_STATE            AS "设计状态",
       MLA.APPROVAL_STATE          AS "申请审核状态",
       MLA.TERMINATION_APPROVAL_STATE AS "终止审批状态",
       MLA.SETTLEMENT_CONFIRM_STATE AS "结算确认状态",
       MLA.CRM_ORDER_CODE          AS "CRM单号",
       MLA.CRM_ORDER_STATUS        AS "CRM订单状态",
       MLA.ERROR_INFO              AS "异常问题",
       MLA.RELATION_APPLY_CODE     AS "关联单据"
FROM DESIGN_APPLY MLA
WHERE MLA.APPLY_TYPE_ONE = 'design'
  AND MLA.PAGE_TYPE = :pageType
  AND (:applyCode IS NULL OR MLA.APPLY_CODE LIKE '%' || :applyCode || '%')
  AND (:approvalState IS NULL OR MLA.APPROVAL_STATE = :approvalState)
  AND (:applyType IS NULL OR MLA.APPLY_TYPE = :applyType)
  AND (:startDate IS NULL OR MLA.CREATE_DATE >= TO_DATE(:startDate, 'YYYY-MM-DD'))
  AND (:endDate IS NULL OR MLA.CREATE_DATE < TO_DATE(:endDate, 'YYYY-MM-DD') + 1)
ORDER BY MLA.CREATE_DATE DESC;
```
