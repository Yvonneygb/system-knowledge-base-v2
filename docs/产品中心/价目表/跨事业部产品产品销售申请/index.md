<KbCard num="1" title="重点逻辑1：申请单号自动生成 `编码规则`">
<ul><li><strong>业务意义</strong>：保证申请单号唯一且可追溯，无需用户手动填写</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：新建保存时，后端通过编码规则CROSS_BU_APP_FORM_CODE自动生成申请单号</li></ul>
<ul><li>第2点：申请单号生成后不可编辑，前端展示为禁用状态</li></ul>
</KbCard>

<KbCard num="2" title="重点逻辑2：事业部自动填充 `当前用户事业部`">
<ul><li><strong>业务意义</strong>：申请单归属当前登录用户所在事业部，无需手动选择</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：新建保存时，若事业部编码为空，后端自动填充当前登录用户的事业部编码</li></ul>
<ul><li>第2点：事业部前端展示为禁用状态，不可编辑</li></ul>
</KbCard>

<KbCard num="3" title="重点逻辑3：明细行类型联动 `新增/失效`">
<ul><li><strong>业务意义</strong>：区分产品是新增跨事业部销售还是失效已有跨事业部销售</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：类型为"新增"时，有效开始时间和有效结束时间必填，且开始时间须大于等于今天，结束时间须大于等于开始时间</li></ul>
<ul><li>第2点：类型为"失效"时，有效开始时间和有效结束时间自动清空且禁用编辑</li></ul>
<ul><li>第3点：类型切换时前端实时联动时间字段的必填和禁用状态</li></ul>
</KbCard>

<KbCard num="4" title="重点逻辑4：审批通过同步写入销售清单 `下游同步`">
<ul><li><strong>业务意义</strong>：审批通过后申请明细落地为正式销售清单，驱动后续跨事业部销售</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：OA审批通过或流程结束时，遍历申请单所有明细行</li></ul>
<ul><li>第2点：对每个产品编码，若销售清单中已存在该事业部的有效记录，则先失效旧记录</li></ul>
<ul><li>第3点：写入新的销售清单记录，状态由明细类型转换：新增→有效，失效→失效</li></ul>
<ul><li>第4点：审计字段（创建人、更新人、创建时间、更新时间）取申请单的审计信息</li></ul>
</KbCard>

<KbCard num="5" title="重点逻辑5：失效联动价目表 `价格联动`">
<ul><li><strong>业务意义</strong>：产品失效跨事业部销售时，同步终止该产品在目标事业部价目表中的有效价格</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>

<p><strong>详细逻辑</strong></p>

<h4>报错36：权限不足</h4>
<ul><li><strong>触发条件</strong>：用户访问页面或点击按钮时，未拥有对应权限编码</li><li><strong>逻辑分析</strong>：前端Button组件通过permissionList配置权限编码（如hzero.c.crm.cross-bu-app.button.create/save/edit/submit/export/import等），HZERO平台校验当前用户角色是否包含该权限编码。</li><li><strong>排查SQL</strong>：</li></ul>

```sql
SELECT U.REAL_NAME AS 用户名, R.NAME AS 角色名, P.CODE AS 权限编码
  FROM HZERO.IAM_USER U
    JOIN HZERO.IAM_MEMBER M ON U.ID = M.MEMBER_ID
    JOIN HZERO.IAM_ROLE R ON M.ROLE_ID = R.ID
    JOIN HZERO.IAM_ROLE_PERMISSION RP ON R.ID = RP.ROLE_ID
    JOIN HZERO.IAM_PERMISSION P ON RP.PERMISSION_ID = P.ID
  WHERE P.CODE LIKE 'hzero.c.crm.cross-bu-app%';
```
