<KbCard num="1" title="重点逻辑1：内外部用户差异化展示 `用户类型区分`">
<ul><li><strong>业务意义</strong>：内部用户可查看所有价目表数据，经销商用户仅能查看自己合同渠道内的产品价格</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：后端通过UserContextUtil获取用户类型（D-经销商，E-内部用户）</li></ul>
<ul><li>第2点：经销商用户查询时，系统自动获取其有效合同渠道列表，SQL中按渠道过滤产品</li></ul>
<ul><li>第3点：经销商用户若未签合同（渠道列表为空），直接抛出异常"未签合同，不允许查询该产品价目表明细"</li></ul>
<ul><li>第4点：前端根据用户类型隐藏"价目表名称"列（经销商不可见），"币种"查询条件仅内部用户可见</li></ul>
</KbCard>

<KbCard num="2" title="重点逻辑2：经销商币种自动匹配 `币种控制`">
<ul><li><strong>业务意义</strong>：经销商用户看到的价格币种由其客商信息决定，不能手动切换</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：内部用户可手动选择币种查询条件，不传则不过滤</li></ul>
<ul><li>第2点：经销商用户的币种由其客商（LNK_ACCNT）的currency字段决定，忽略前端传入的币种</li></ul>
<ul><li>第3点：若经销商客商未配置币种，默认使用CNY</li></ul>
</KbCard>

<KbCard num="3" title="重点逻辑3：海外事业部人民币多价目表 `海外特殊处理`">
<ul><li><strong>业务意义</strong>：海外事业部使用人民币时，区分出口客户和非出口客户匹配不同价目表</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：仅当经销商用户+事业部名称为"海外事业部"+币种为CNY时触发</li></ul>
<ul><li>第2点：出口客户（exportType=Y）匹配"海外事业部价目表_CNY（出口）"</li></ul>
<ul><li>第3点：非出口客户匹配"海外事业部价目表"</li></ul>
<ul><li>第4点：其余场景不设置专属价目表名称，SQL不追加价目表名称过滤</li></ul>
</KbCard>

<KbCard num="4" title="重点逻辑4：含安装价格自动计算 `价格计算`">
<ul><li><strong>业务意义</strong>：标准单价（含安装）=标准单价（不含安装）+安装单价，方便用户直接查看含安装总价</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：SQL中standardPriceWithInstall = t1.price + nvl(t1.INSTALL_PRICE, 0)</li></ul>
<ul><li>第2点：standardPriceNoInstall = t1.price（价目表明细表的原价）</li></ul>
<ul><li>第3点：installPrice = t1.INSTALL_PRICE（安装单价）</li></ul>
</KbCard>

<KbCard num="5" title="重点逻辑5：瓷砖库存数单位换算 `库存换算`">
<ul><li><strong>业务意义</strong>：瓷砖产品的库存数按计费单位与产品基本单位的转换率换算后展示</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：当产品线（LH_PROD_LINE）为CeramicTile时，库存数=Round(原始库存数/转换率, 2)</li></ul>
<ul><li>第2点：转换率通过cux_inv_convert_ex_pub.inv_um_convert函数计算（产品编码、计费单位、产品基本单位）</li></ul>
<ul><li>第3点：非瓷砖产品直接展示原始库存数</li></ul>
</KbCard>

<KbCard num="6" title="重点逻辑6：仅查询有效价格 `时效控制`">
<ul><li><strong>业务意义</strong>：只展示当前日期在有效区间内且价格状态为有效的记录</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：SQL条件PRICE_STATUS='Y'，过滤掉无效价格</li></ul>
<ul><li>第2点：SQL条件trunc(SYSDATE) BETWEEN trunc(eff_start_date) AND trunc(eff_end_date)，仅展示当前有效的价格</li></ul>
</KbCard>

```sql
        t1.created AS created,
        T1.CREATED_BY AS createdBy,
        TO_CHAR(T1.LAST_UPD, 'yyyy-mm-dd hh24:mi:ss') AS lastUpdated,

        t1.price AS standardPriceNoInstall,
        t2.SM_STATE AS smState,

            WHEN t2.LH_PROD_LINE = 'CeramicTile' THEN (
                Round(t1.INVENTORY_QTY / nvl(cux_inv_convert_ex_pub.inv_um_convert(t2.prod_code, t1.price_unit, t2.prod_unit), 1), 2)
            )
            ELSE t1.INVENTORY_QTY
        END) AS inventoryQTY,
        t1.price_unit AS priceUnit,
        nvl(cux_inv_convert_ex_pub.inv_um_convert(t2.prod_code, t1.price_unit, t2.prod_unit), 1) AS conversionRate,
```

```sql
         CASE WHEN TRUNC(SYSDATE) BETWEEN TRUNC(T1.EFF_START_DATE) AND TRUNC(T1.EFF_END_DATE)
              THEN '有效' ELSE '失效' END AS 当前是否有效
  FROM LNK_PRICE_LIST_ITEM T1
    JOIN LNK_PROD T2 ON T1.PROD_ID = T2.ROW_ID
    JOIN LNK_PRICE_LIST T3 ON T1.HEAD_ID = T3.ROW_ID
    JOIN REL_CRM_AE_ORG O ON T3.DEPT_ID = O.CRM_ORG_ID
  WHERE O.AE_ORG_CODE = :deptCode
    AND T3.CURRENCY = :currency
  ORDER BY T2.PROD_CODE;
```
