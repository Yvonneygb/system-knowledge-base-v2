<KbCard num="1" title="重点逻辑1：内外部用户数据隔离 `权限控制`">
<ul><li><strong>业务意义</strong>：内部员工和外部经销商看到的产品范围不同，确保经销商只能看到有价格且渠道匹配的产品，内部员工可按事业部查看更多产品</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：内部用户（userType=E）——"商品检索"Tab展示产品事业部不为空且物料类型不为"配件"的产品，且需满足产品事业部等于用户所属事业部、或虽不等于但在用户所属事业部价目表中有有效价格</li></ul>
<ul><li>第2点：内部用户——"配件&amp;其它"Tab展示产品事业部为空、或物料类型为"配件"的产品</li></ul>
<ul><li>第3点：内部管理员（拥有hzero.product_data.product_info.product_list.ps.admin_search权限且range=ALL）——"商品检索"Tab展示所有产品事业部不为空且非配件的产品，"配件&amp;其它"Tab展示所有事业部为空或配件的产品，不受价目表价格限制</li></ul>
<ul><li>第4点：外部用户（userType=D）——"商品检索"Tab展示产品事业部不为空、在经销商有效合同渠道内、价目表有价格、生命状态不为Z1/Z3、且非配件的产品</li></ul>
<ul><li>第5点：外部用户——"其它"Tab展示产品事业部为空、在经销商有效合同渠道内、价目表有价格、生命状态不为Z1/Z3、且非配件的产品</li></ul>
<ul><li>第6点：外部用户不可使用管理员全量查询权限，若分配了ALL权限会报错"分配了管理员权限，不可查询，请联系管理员处理！"</li></ul>
</KbCard>

<KbCard num="2" title="重点逻辑2：外部用户字段隐藏 `界面差异`">
<ul><li><strong>业务意义</strong>：外部经销商不需要看到品牌事业部、品牌、上市/淘汰日期、产品推广等级、制造或采购等内部管理字段</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：当用户userType为'D'（外部用户）时，隐藏以下字段：品牌事业部（deptId）、品牌（brand）、上市日期（launchDate）、淘汰日期（obsolescenceDate）、产品推广等级（prodPromoteGrade）、制造或采购（planningMakeBuyCodeMir）</li></ul>
<ul><li>第2点：外部用户的"配件&amp;其它"Tab名称显示为"其它"（去掉"配件&amp;"前缀）</li></ul>
<ul><li>第3点：外部用户隐藏"产品图册-导入"和"产品附件-导入"按钮，仅保留"导出"按钮</li></ul>
<ul><li>第4点：外部用户的生命状态值集使用CRM.PRODUCT_Z_STATE_NAME（含名称），内部用户使用CRM.PRODUCT_Z_STATE（含编码+名称）</li></ul>
</KbCard>

<KbCard num="3" title="重点逻辑3：默认查询条件与智能清空 `查询优化`">
<ul><li><strong>业务意义</strong>：避免全表扫描，默认只查近一个月创建的产品；当用户输入精确查询条件时自动清空时间范围，提升查询效率</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：页面加载时默认设置创建时间范围为近一个月（开始=当前日期-1月，结束=当前日期）</li></ul>
<ul><li>第2点：当用户在"产品编码""产品名称""型号"任一字段输入值时，自动清空创建时间默认范围，改为按精确条件查询</li></ul>
<ul><li>第3点：首次查询时若无任何查询参数（除organizationId和selectType外），自动补充默认创建时间范围并触发查询</li></ul>
<ul><li>第4点：管理员权限检查通过后（hzero.product_data.product_info.product_list.ps.admin_search），查询时传入range=ALL参数，后端据此跳过价目表价格过滤</li></ul>
</KbCard>

<KbCard num="4" title="重点逻辑4：价目表价格关联与海外事业部特殊处理 `价格逻辑`">
<ul><li><strong>业务意义</strong>：产品展示需关联价目表获取标准单价，海外事业部人民币场景存在多个价目表，需按出口客户标识精确匹配</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：通过LNK_PRICE_LIST和LNK_PRICE_LIST_ITEM关联查询产品价格，条件为价目表币种=经销商币种（内部用户默认CNY）、价目表事业部=用户所属事业部、价格状态为Y且在有效期内</li></ul>
<ul><li>第2点：海外事业部+人民币场景下，根据经销商账户的出口客户标识（outAccount）匹配专属价目表名称：出口客户匹配"海外事业部价目表_CNY（出口）"，非出口匹配"海外事业部价目表"</li></ul>
<ul><li>第3点：内部用户无出口标识，海外事业部场景默认取"海外事业部价目表"</li></ul>
<ul><li>第4点：价格取MAX(CASE WHEN PRICE_STATUS=Y AND EFF_START_DATE&lt;=TRUNC(sysdate) AND EFF_END_DATE&gt;=TRUNC(sysdate) THEN price END)，即生效价格中的最大值</li></ul>
</KbCard>

<KbCard num="5" title="重点逻辑5：多值查询拆分 `查询增强`">
<ul><li><strong>业务意义</strong>：支持物料类型和产品编码多值查询，提升批量查询效率</li></ul>
<ul><li><strong>具体逻辑描述</strong></li></ul>
<ul><li>第1点：物料类型（lhProdSign）含分隔符时，拆分为列表使用IN查询，避免正则CONNECT BY性能问题</li></ul>
<ul><li>第2点：产品编码（prodCode）含分隔符时，拆分为列表使用IN查询</li></ul>
</KbCard>

<ul><li><strong>触发条件</strong>：常显，需拥有hzero.product_data.product_info.product_list.ps.export权限</li><li><strong>执行逻辑</strong>：</li><li>第1点：内部用户（userType≠D）调用接口GET /v1/&#123;organizationId&#125;/prod/internal/export?selectType=general或other</li><li>第2点：外部用户（userType=D）调用接口GET /v1/&#123;organizationId&#125;/prod/external/export?selectType=general或other</li><li>第3点：导出参数取当前查询条件栏的值，包括管理员range=ALL参数</li><li>第4点：异步导出，导出文件名"产品明细导出"</li><li>第5点：内部用户导出VO为LnkProdInternalExport，外部用户导出VO为LnkProdExternalExport（字段不同）</li><li><strong>接口调用</strong>：GET /v1/&#123;organizationId&#125;/prod/&#123;internal|external&#125;/export</li><li><strong>排查SQL</strong>：</li></ul>

```sql
-- 内部用户-商品检索Tab导出查询
SELECT T1.ROW_ID, T1.PROD_CODE, T1.PROD_NAME, T1.LH_PROD_MODEL, T1.PROD_SERIES,
       T1.LH_PROD_CHANNEL, T1.PROD_STATUS, T1.LH_PROD_SIGN, T1.SM_STATE,
       T1.DEPT_ID, T2.ORG_NAME, T1.BRAND, T1.PROD_STANDARD, T1.LH_PROD_LINE,
       T1.LAUNCH_DATE, T1.OBSOLESCENCE_DATE, T1.PROD_PROMOTE_GRADE,
       T1.PLANNING_MAKE_BUY_CODE_MIR, T1.PROD_POSITIONING, T1.PROD_ATTRIBUTION_CHANNEL,
       T1.PACKAGE_NUMBER, T1.PROD_NAME_ABBR, T1.LH_PROD_COLOR, T1.IS_SECURITY,
       T1.LH_IS_DEDICATED, T1.LH_IS_DEPOSIT_OR_NOT, T1.SECONDARY_MATERIAL_TYPE,
       T1.CONVERSION_RATE, T1.PRICE, T1.CREATED, T1.LAST_UPD
FROM LNK_PROD T1
  LEFT JOIN LNK_ORG_EXT T2 ON T1.DEPT_ID = T2.ROW_ID
  LEFT JOIN (
    SELECT PLI.PROD_ID, 1 AS HAS_PRICE,
           MAX(CASE WHEN PLI.PRICE_STATUS = 'Y'
                     AND PLI.EFF_START_DATE <= TRUNC(SYSDATE)
                     AND PLI.EFF_END_DATE   >= TRUNC(SYSDATE)
                    THEN PLI.PRICE END) AS PRICE
    FROM LNK_PRICE_LIST PL
      JOIN LNK_PRICE_LIST_ITEM PLI ON PL.ROW_ID = PLI.HEAD_ID
    WHERE PL.CURRENCY = 'CNY'  -- 经销商币种
      AND PL.DEPT_ID = :userDeptId  -- 用户所属事业部
    GROUP BY PLI.PROD_ID
  ) PLI ON PLI.PROD_ID = T1.ROW_ID
WHERE T1.DEPT_ID IS NOT NULL
  AND T1.LH_PROD_SIGN <> '配件'
  AND (T1.DEPT_ID = :userDeptId OR (T1.DEPT_ID <> :userDeptId AND PLI.HAS_PRICE = 1))
ORDER BY T1.CREATED DESC, T1.ROW_ID DESC;
```
