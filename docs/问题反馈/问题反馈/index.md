<div class="kl-wrap">
<KbCard num="1" title="重点逻辑1：反馈单状态流转">
<ul><li><strong>业务意义</strong>：反馈单有完整的状态生命周期，不同状态下可执行的操作不同，确保问题处理流程闭环。</li><li><strong>具体逻辑描述</strong>：状态值集 <code>MBO.FEEDBACK_STATE</code>，状态流转为：草稿→已提交→处理中→已回答→已完成；已提交→已取消。新增反馈单默认为草稿状态，提交后变为已提交，事业部回复后变为处理中/已回答，问题完成后变为已完成。</li></ul>
</KbCard>

<KbCard num="2" title="重点逻辑2：问题类型配置">
<ul><li><strong>业务意义</strong>：对问题进行分类管理，便于统计分析和分派处理。</li><li><strong>具体逻辑描述</strong>：问题类型分为产品问题、订单问题、系统问题、其他。通过值集配置，前端 Select 组件加载选项。</li></ul>
</KbCard>

<KbCard num="3" title="重点逻辑3：评价功能">
<ul><li><strong>业务意义</strong>：经销商对问题处理结果进行满意度评价，帮助改进服务质量。</li><li><strong>具体逻辑描述</strong>：问题状态为已完成时，经销商可弹出评价弹窗，填写星级评分（1-5星）和评价内容，提交后调用 <code>feedback/evaluate</code> 接口写入 <code>FEEDBACK</code> 表的 <code>GRADE</code> 和 <code>EVALUATE_CONTENT</code> 字段。</li></ul>
</KbCard>

<KbCard num="4" title="重点逻辑4：附件上传">
<ul><li><strong>业务意义</strong>：支持经销商上传问题相关截图或文件，便于问题定位和处理。</li><li><strong>具体逻辑描述</strong>：详情页提供附件上传组件，调用 HZERO 文件服务上传文件，文件信息关联到反馈单。</li></ul>
</KbCard>

<h4>详情页按钮详细逻辑</h4>
<h5>按钮1：暂存（详情页头部）</h5>
<p><strong>触发条件</strong>：点击"暂存"按钮（isAdd/isEdit 且 state≠2）</p>
<p><strong>执行逻辑</strong>：</p>
<ol><li>调用 <code>POST feedback/save</code> 接口保存反馈单草稿</li><li>提交数据：<code>getFormData()</code>（包含表单数据和附件列表）</li><li>成功后关闭标签页 <code>handleCloseTab()</code></li></ol>
<h5>按钮2：提交（详情页头部）</h5>
<p><strong>触发条件</strong>：点击"提交"按钮（isAdd/isEdit 且 (!state \|\| state=1)）</p>
<p><strong>执行逻辑</strong>：</p>
<ol><li>先校验表单 <code>baseFormDS.validate()</code></li><li>校验通过后调用 <code>POST feedback/submit</code> 接口提交反馈单</li><li>提交数据：<code>getFormData()</code></li><li>成功后关闭标签页 <code>handleCloseTab()</code></li></ol>
<h5>按钮3：取消（详情页头部）</h5>
<p><strong>触发条件</strong>：点击"取消"按钮（isEdit/isDetail 且 state 在 [1,3,4,5]）</p>
<p><strong>执行逻辑</strong>：</p>
<ol><li>弹出确认框 <code>Modal.confirm(&#123; title: '提示', children: '确认取消该反馈？' &#125;)</code></li><li>确认后调用 <code>POST feedback/cancel/$&#123;id&#125;</code> 接口取消反馈单</li><li>成功后关闭标签页 <code>handleCloseTab()</code></li></ol>
<h5>按钮4：再反馈（详情页头部）</h5>
<p><strong>触发条件</strong>：点击"再反馈"按钮（isDetail 且 state 在 [4,5]）</p>
<p><strong>执行逻辑</strong>：</p>
<ol><li>先校验表单 <code>baseFormDS.validate()</code></li><li>提取再反馈内容：<code>&#123; commentContent, id, fileDTOList: attachmentsRef.current &#125;</code></li><li>调用 <code>POST feedback/comment</code> 接口提交再反馈内容</li><li>成功后关闭标签页 <code>handleCloseTab()</code></li></ol>
<h4>详情页组件</h4>
<h5>反馈回复记录组件（FeedbackChat）</h5>
<p>详情页底部展示反馈回复记录组件，以聊天气泡形式展示反馈和回复的历史记录：</p>
<ul><li>每条记录显示操作人、所属门店、操作时间</li><li>经销商消息在左侧，事业部消息在右侧（根据 <code>from</code> 参数判断）</li><li>支持图片预览（Picture 组件）、视频播放（video 标签）、文件下载（a 标签）</li><li>附件按 tab 分组展示</li></ul>

<ul><li>显示评价星级（Rate 组件，allowHalf，allowClear，disabled）</li><li>显示评价内容（TextArea，disabled）</li><li>数据通过 <code>evaluationRef.current?.loadData()</code> 加载</li></ul>

FROM FEEDBACK
GROUP BY QUESTIONID
HAVING COUNT(*) > 1;
