# 工程管理-合同与折扣-工程自营签收

> **说明**：本菜单前端代码存在于arrow-ae模块的SelfOperatedEngineeringSign目录，但路由未在routes.ts中注册，可能通过菜单管理动态配置。后端使用旧CRM网关模式调用。

---

## 业务流程

### 业务流程图

```text
开始 → ★新建工程自营签收★ → 选择项目/合同 → 填写签收信息 → 保存 → 提交审批 → ⚖审批通过？
  ├─（通过）签收完成 → 结束
  └─（拒绝）可修改后重新提交 → 结束
```

### 上游依赖

| 上游模块 | 依赖类型 | 依赖说明 | 依赖成立条件 |
|---------|---------|---------|------------|
| 项目主档 | 数据依赖 | 选择工程项目 | 项目已创建 |
| 合同主档 | 数据依赖 | 关联工程合同 | 合同已签订 |
| 旧CRM服务 | 服务依赖 | 通过网关调用旧CRM接口 | 旧CRM服务可用 |
| OA工作流引擎 | 服务依赖 | 提交审批触发工作流 | 工作流已配置 |

### 下游影响

- 影响1：工程核销
  - 签收完成后数据进入工程核销流程

## 重点逻辑

### 重点逻辑1：旧CRM网关调用 `网关模式`

- **业务意义**：通过CRM网关调用旧系统接口，兼容历史系统

- **具体逻辑描述**

#### 报错1：旧CRM网关调用失败
- **触发条件**：提交工程自营签收时，调用旧CRM网关接口失败
- **逻辑分析**：提交方法中调用旧CRM网关推送签收数据，若失败则记录错误信息。可能原因：旧CRM服务不可用、网关配置错误、网络异常。需检查旧CRM服务连通性和网关配置
- **排查SQL**：
  ```sql
  SELECT ddh.BILL_NO, ddh.PROJECT_CODE, ddh.CONTRACT_CODE, ddh.HZ_APPROVE_STATUS,
         ddl.INTF_MSG AS ERP推送状态
  FROM DRP_DIFFPROCBILL_HEADER ddh
  LEFT JOIN DRP_DIFFPROCBILL_LINE ddl ON ddh.BILL_NO = ddl.BILL_NO
  WHERE ddh.BILL_NO = :billNo
  -- 检查签收单数据完整性
  ```
