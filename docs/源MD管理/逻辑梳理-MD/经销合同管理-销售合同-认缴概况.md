#### 报错1：查询无数据
- **触发条件**：用户按经销商/合同/年度查询认缴概况，search接口返回空结果集
- **逻辑分析**：认缴概况基于CM_CONTRACT_PAYMENT_SUMMARY表，汇总展示保证金认缴金额（SUBSCRIPTION_AMT）、已缴金额（PAID_AMT）、未缴金额（UNPAID_AMT=认缴-已缴）。无数据根因有三类：(1)无认缴申请记录，认缴申请（CM_CONTRACT_PAYMENT_APPLY）未创建或未审批通过（HZ_APPROVE_STATUS != 'APPROVED'），概况表未汇总；(2)保证金到款（CM_DEPOSITS_PAYMENT）数据未同步到概况表；(3)查询条件（CONTRACT_NO+CUSTOMER_NAME）与概况记录不匹配。需先确认认缴申请审批状态及保证金到款情况
- **排查SQL**：
  ```sql
  SELECT SUMMARY_ID, CONTRACT_NO, CUSTOMER_NAME, SUBSCRIPTION_AMT, PAID_AMT, UNPAID_AMT
  FROM CM_CONTRACT_PAYMENT_SUMMARY
  WHERE (CONTRACT_NO = #{contractNo} OR #{contractNo} IS NULL)
    AND (CUSTOMER_NAME = #{customerName} OR #{customerName} IS NULL);
  -- 核查上游认缴申请审批状态
  SELECT APPLY_NO, CONTRACT_NO, CUSTOMER_NAME, APPLY_AMT, HZ_APPROVE_STATUS
  FROM CM_CONTRACT_PAYMENT_APPLY
  WHERE CONTRACT_NO = #{contractNo} AND HZ_APPROVE_STATUS = 'APPROVED';
  ```

#### 报错2：合同类型、事业部、经销商不能为空
- **触发条件**：查询认缴概况或保存概况数据时，CONTRACT_TYPE、ENTID、CUSTOMER_ID任一参数为空
- **逻辑分析**：CmContractPaymentSummaryServiceImpl在search和save方法中校验CONTRACT_TYPE、ENTID、CUSTOMER_ID非空。这三个字段是认缴概况数据隔离和汇总的核心维度，缺失将导致查询无数据范围或汇总无归属。通常由前端未正确传入查询条件或保存参数导致
- **排查SQL**：
  ```sql
  SELECT SUMMARY_ID, CONTRACT_NO, CUSTOMER_NAME, CONTRACT_TYPE, ENTID,
         SUBSCRIPTION_AMT, PAID_AMT, UNPAID_AMT
  FROM CM_CONTRACT_PAYMENT_SUMMARY
  WHERE CONTRACT_TYPE IS NULL OR ENTID IS NULL OR CUSTOMER_ID IS NULL;
  ```

#### 报错3：保证金标准设定未配置，请先配置
- **触发条件**：保存认缴概况数据时，根据事业部和合同类型查询保证金标准（CM_DEPOSITS_PAY_STANDARD）返回空
- **逻辑分析**：CmContractPaymentSummaryServiceImpl在save方法中查询保证金标准，保证金标准是计算应缴保证金和判断缴清状态的依据。标准未配置将导致认缴概况数据无法正确计算缴清标识（PAY_COMPLETE）。需先在保证金标准配置中维护对应事业部和合同类型的标准
- **排查SQL**：
  ```sql
  SELECT S.SUMMARY_ID, S.CONTRACT_NO, S.CUSTOMER_NAME, S.CONTRACT_TYPE, S.ENTID,
         P.PAY_STANDARD_ID, P.STANDARD_AMT
  FROM CM_CONTRACT_PAYMENT_SUMMARY S
  LEFT JOIN CM_DEPOSITS_PAY_STANDARD P
    ON S.ENTID = P.ENTID AND S.CONTRACT_TYPE = P.CONTRACT_TYPE
  WHERE P.PAY_STANDARD_ID IS NULL;
  ```

#### 报错4：网络请求失败
- **触发条件**：前端调用cm-contract-payment-summarys相关接口时，后端服务不可达或请求超时
- **逻辑分析**：前端通过axios调用AE_BUSINESS服务，网络异常、服务宕机、网关超时均会触发。前端拦截器统一捕获并toast提示。需检查AE_BUSINESS服务状态、网络连通性、网关配置
- **排查SQL**：
  ```sql
  SELECT '网络层异常，无SQL排查' AS 提示 FROM DUAL;
  ```

#### 报错5：权限不足，无法操作
- **触发条件**：当前用户对认缴概况查询、导出等操作无对应功能权限或数据权限
- **逻辑分析**：后端通过权限注解校验用户角色，前端通过菜单和按钮权限控制显隐。用户无权限时后端返回403，前端拦截器toast提示。需在权限管理中为用户分配对应角色
- **排查SQL**：
  ```sql
  SELECT '权限层异常，请核查用户角色配置' AS 提示 FROM DUAL;
  ```
