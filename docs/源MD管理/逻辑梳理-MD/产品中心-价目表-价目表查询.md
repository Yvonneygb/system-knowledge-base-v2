## 业务流程

### 业务流程图

```text
开始 → 设置查询条件（产品编码/名称/型号/品类/物料类型/生命状态/产品定位/币种） → 查询 → 查看结果 → 结束
                                                    ↓
                                            导出 → 下载Excel文件 → 结束
```

## 重点逻辑

### 重点逻辑1：内外部用户差异化展示 `用户类型区分`

- **业务意义**：内部用户可查看所有价目表数据，经销商用户仅能查看自己合同渠道内的产品价格

- **具体逻辑描述**

  - 第1点：后端通过UserContextUtil获取用户类型（D-经销商，E-内部用户）

  - 第2点：经销商用户查询时，系统自动获取其有效合同渠道列表，SQL中按渠道过滤产品

  - 第3点：经销商用户若未签合同（渠道列表为空），直接抛出异常"未签合同，不允许查询该产品价目表明细"

  - 第4点：前端根据用户类型隐藏"价目表名称"列（经销商不可见），"币种"查询条件仅内部用户可见

### 重点逻辑2：经销商币种自动匹配 `币种控制`

- **业务意义**：经销商用户看到的价格币种由其客商信息决定，不能手动切换

- **具体逻辑描述**

  - 第1点：内部用户可手动选择币种查询条件，不传则不过滤

  - 第2点：经销商用户的币种由其客商（LNK_ACCNT）的currency字段决定，忽略前端传入的币种

  - 第3点：若经销商客商未配置币种，默认使用CNY

### 重点逻辑3：海外事业部人民币多价目表 `海外特殊处理`

- **业务意义**：海外事业部使用人民币时，区分出口客户和非出口客户匹配不同价目表

- **具体逻辑描述**

  - 第1点：仅当经销商用户+事业部名称为"海外事业部"+币种为CNY时触发

  - 第2点：出口客户（exportType=Y）匹配"海外事业部价目表_CNY（出口）"

  - 第3点：非出口客户匹配"海外事业部价目表"

  - 第4点：其余场景不设置专属价目表名称，SQL不追加价目表名称过滤

### 重点逻辑4：含安装价格自动计算 `价格计算`

- **业务意义**：标准单价（含安装）=标准单价（不含安装）+安装单价，方便用户直接查看含安装总价

- **具体逻辑描述**

  - 第1点：SQL中standardPriceWithInstall = t1.price + nvl(t1.INSTALL_PRICE, 0)

  - 第2点：standardPriceNoInstall = t1.price（价目表明细表的原价）

  - 第3点：installPrice = t1.INSTALL_PRICE（安装单价）

### 重点逻辑5：瓷砖库存数单位换算 `库存换算`

- **业务意义**：瓷砖产品的库存数按计费单位与产品基本单位的转换率换算后展示

- **具体逻辑描述**

  - 第1点：当产品线（LH_PROD_LINE）为CeramicTile时，库存数=Round(原始库存数/转换率, 2)

  - 第2点：转换率通过cux_inv_convert_ex_pub.inv_um_convert函数计算（产品编码、计费单位、产品基本单位）

  - 第3点：非瓷砖产品直接展示原始库存数

### 重点逻辑6：仅查询有效价格 `时效控制`

- **业务意义**：只展示当前日期在有效区间内且价格状态为有效的记录

- **具体逻辑描述**

  - 第1点：SQL条件PRICE_STATUS='Y'，过滤掉无效价格

  - 第2点：SQL条件trunc(SYSDATE) BETWEEN trunc(eff_start_date) AND trunc(eff_end_date)，仅展示当前有效的价格

> 列表查询SQL（Mapper: LnkPriceListItemMapper.xml → selectPriceListItemListPage）：

```sql
SELECT  T1.ROW_ID AS id,
        t1.created AS created,
        T1.CREATED_BY AS createdBy,
        TO_CHAR(T1.LAST_UPD, 'yyyy-mm-dd hh24:mi:ss') AS lastUpdated,
        T1.LAST_UPD_BY AS lastUpdatedBy,
        t2.prod_code AS prodCode,
        t2.prod_name AS lhProdName,
        t2.LH_PROD_MODEL AS lhProdModel,
        (t1.price + nvl(t1.INSTALL_PRICE, 0)) AS standardPriceWithInstall,
        t1.INSTALL_PRICE AS installPrice,
        t1.price AS standardPriceNoInstall,
        t2.SM_STATE AS smState,
        t1.PROD_POSITIONING AS prodPositioning,
        (CASE
            WHEN t2.LH_PROD_LINE = 'CeramicTile' THEN (
                Round(t1.INVENTORY_QTY / nvl(cux_inv_convert_ex_pub.inv_um_convert(t2.prod_code, t1.price_unit, t2.prod_unit), 1), 2)
            )
            ELSE t1.INVENTORY_QTY
        END) AS inventoryQTY,
        t1.price_unit AS priceUnit,
        nvl(cux_inv_convert_ex_pub.inv_um_convert(t2.prod_code, t1.price_unit, t2.prod_unit), 1) AS conversionRate,
        TO_CHAR(T1.eff_start_date, 'yyyy-mm-dd') AS effStartDate,
        TO_CHAR(T1.eff_end_date, 'yyyy-mm-dd') AS effEndDate,
        T2.LH_PROD_TYPE AS lHprodType,
        T2.LH_PROD_TYPE1 AS lHprodType1,
        T2.LH_PROD_TYPE2 AS lHprodType2,
        t2.LH_PROD_SIGN AS lHprodSign,
        t3.CURRENCY AS currency,
        t3.PRICE_LIST_NAME AS priceListName
FROM LNK_PRICE_LIST_ITEM t1
    LEFT JOIN LNK_PROD t2 ON t1.prod_id = t2.row_id
    LEFT JOIN LNK_PRICE_LIST t3 ON t1.head_id = t3.row_id
WHERE 1=1
    AND t1.PRICE_STATUS = 'Y'                                          -- 仅有效价格
    AND trunc(SYSDATE) BETWEEN trunc(T1.eff_start_date) AND trunc(T1.eff_end_date)  -- 当前有效期内
    AND t1.head_id IN (SELECT l.ROW_ID                                 -- 当前事业部价目表
                        FROM lnk_price_list l
                        JOIN rel_crm_ae_org o ON l.dept_id = o.crm_org_id
                        WHERE o.AE_ORG_CODE = #{deptCode}
                        AND l.CURRENCY = #{currency})                  -- 币种过滤
    -- 经销商用户：按有效合同渠道过滤
    -- AND (t2.lh_prod_channel = #{channel} OR like匹配)
    -- 海外事业部人民币场景：AND t3.PRICE_LIST_NAME = #{overseasPriceListName}
    -- 产品编码：t2.prod_code = #{prodCode} 或 IN (#{prodCodeList})
    -- 产品名称(like)、产品大类(like)、产品中类(like)、产品小类(like)、产品型号(like)
    -- 定价时的产品定位(=)、物料类型(=)、生命状态(=)
```

> 经销商合同渠道校验SQL（Mapper: checkProdCodeInContractChannel）：

```sql
SELECT COUNT(1)
FROM LNK_PROD p
WHERE p.prod_code = #{prodCode}
    AND EXISTS (
        SELECT 1
        FROM lnk_contract t
        JOIN lnk_contract_channel c ON t.row_id = c.lnk_contract_id
        WHERE t.accnt_id = (SELECT ac.row_id FROM lnk_accnt ac WHERE ac.acct_code = #{dealerCode})
            AND (t.IS_DELIVERY = 'N' OR t.IS_DELIVERY IS NULL)
            AND t.agr_status = 'Agree'
            AND t.EFFECTIVE_START_DT <= sysdate
            AND (t.EFFECTIVE_END_DT >= sysdate OR t.delay_date > sysdate)
            AND (p.lh_prod_channel = c.channel_val
                 OR p.lh_prod_channel LIKE CONCAT(c.channel_val, '/%')
                 OR p.lh_prod_channel LIKE CONCAT(CONCAT('%/', c.channel_val), '/%')
                 OR p.lh_prod_channel LIKE CONCAT('%/', c.channel_val))
    )
```

> **"未签合同，不允许查询该产品价目表明细"详细逻辑**：
> 后端selectPriceListItemListPage方法中，两种场景会抛出此异常：
> 1. 经销商用户的有效合同渠道列表为空（未签任何有效合同）
> 2. 经销商用户查询单个产品编码时，该产品不在其有效合同渠道内
> 排查SQL：

```sql
-- 检查经销商有效合同渠道
SELECT c.channel_val
FROM lnk_contract t
JOIN lnk_contract_channel c ON t.row_id = c.lnk_contract_id
WHERE t.accnt_id = (SELECT ac.row_id FROM lnk_accnt ac WHERE ac.acct_code = #{dealerCode})
    AND (t.IS_DELIVERY = 'N' OR t.IS_DELIVERY IS NULL)
    AND t.agr_status = 'Agree'
    AND t.EFFECTIVE_START_DT <= sysdate
    AND (t.EFFECTIVE_END_DT >= sysdate OR t.delay_date > sysdate);
```

#### 报错2：导出权限不足
- **触发条件**：当前用户无导出权限时，导出按钮不显示；若通过API直接调用导出接口则返回403
- **逻辑分析**：前端PriceTable组件中通过checkPermissions(['hzero.crm.price.list.export'])异步校验导出权限（listConfig.tsx第228行），无权限时hasExportPermission为false，导出按钮不渲染。后端export接口标注@Permission(level=ResourceLevel.ORGANIZATION)，无权限时抛出403异常。
- **排查SQL**：
  ```sql
  -- 检查用户是否拥有价目表导出权限
  SELECT R.CODE AS 角色编码, R.NAME AS 角色名称,
         P.CODE AS 权限编码, P.NAME AS 权限名称
  FROM HZERO.IAM_ROLE R
    JOIN HZERO.IAM_ROLE_PERMISSION RP ON R.ID = RP.ROLE_ID
    JOIN HZERO.IAM_PERMISSION P ON RP.PERMISSION_ID = P.ID
  WHERE P.CODE = 'hzero.crm.price.list.export'
  ORDER BY R.CODE;
  ```

#### 报错3：查询失败
- **触发条件**：列表页加载或点击查询按钮时，后端列表查询接口返回失败
- **逻辑分析**：前端DataSet的transport.read调用GET /v1/{organizationId}/lnk-price-list-item/list接口，后端selectPriceListItemListPage方法通过LnkPriceListItemMapper.selectPriceListItemListPage查询LNK_PRICE_LIST_ITEM关联LNK_PROD、LNK_PRICE_LIST表，并调用cux_inv_convert_ex_pub.inv_um_convert函数计算转换率。若数据库连接异常、SQL执行超时、转换率函数异常或事业部价目表不存在则返回失败，前端DataSet自动提示查询失败。
- **排查SQL**：
  ```sql
  -- 检查当前事业部是否存在有效价目表
  SELECT L.ROW_ID AS 价目表ID, L.PRICE_LIST_NAME AS 价目表名称,
         L.CURRENCY AS 币种, O.AE_ORG_CODE AS 事业部编码
  FROM LNK_PRICE_LIST L
    JOIN REL_CRM_AE_ORG O ON L.DEPT_ID = O.CRM_ORG_ID
  WHERE O.AE_ORG_CODE = :deptCode
    AND L.CURRENCY = :currency;

  -- 检查价目表明细关联的产品资料是否存在
  SELECT T1.ROW_ID AS 明细ID, T1.PROD_ID AS 产品ID,
         T2.PROD_CODE AS 产品编码, T2.PROD_NAME AS 产品名称
  FROM LNK_PRICE_LIST_ITEM T1
    LEFT JOIN LNK_PROD T2 ON T1.PROD_ID = T2.ROW_ID
  WHERE T2.ROW_ID IS NULL;
  ```

#### 报错4：会话过期
- **触发条件**：用户登录会话已失效时执行任意操作（查询/导出）
- **逻辑分析**：前端request请求携带的access_token过期，后端网关拦截返回401状态码，前端axios拦截器检测到401后弹出登录确认框提示"会话过期，请重新登录"，跳转登录页面。价目表查询为纯查询页面，会话过期主要影响查询和导出操作。
- **排查SQL**：
  ```sql
  -- 检查用户登录会话状态
  SELECT U.LOGIN_NAME AS 登录名, T.TOKEN, T.EXPIRE_TIME AS 过期时间,
         T.LAST_CLIENT_TIME AS 最后活跃时间
  FROM HZERO.OAUTH_ACCESS_TOKEN T
    JOIN HZERO.IAM_USER U ON T.USER_ID = U.ID
  WHERE U.LOGIN_NAME = :loginName
  ORDER BY T.EXPIRE_TIME DESC;
  ```

#### 报错5：暂无数据
- **触发条件**：查询条件匹配不到任何有效价格记录，列表展示为空
- **逻辑分析**：后端SQL条件PRICE_STATUS='Y'且trunc(SYSDATE) BETWEEN trunc(EFF_START_DATE) AND trunc(EFF_END_DATE)过滤有效价格，若当前日期不在任何价格有效期内、价格状态非Y、或事业部/币种/渠道过滤后无匹配数据，则返回空列表。前端DataSet接收空数据，列表区域显示"暂无数据"。
- **排查SQL**：
  ```sql
  -- 检查当前事业部有效价格数据
  SELECT T2.PROD_CODE AS 产品编码, T2.PROD_NAME AS 产品名称,
         T1.PRICE AS 标准单价, T1.PRICE_STATUS AS 价格状态,
         T1.EFF_START_DATE AS 有效开始, T1.EFF_END_DATE AS 有效结束,
         CASE WHEN TRUNC(SYSDATE) BETWEEN TRUNC(T1.EFF_START_DATE) AND TRUNC(T1.EFF_END_DATE)
              THEN '有效' ELSE '失效' END AS 当前是否有效
  FROM LNK_PRICE_LIST_ITEM T1
    JOIN LNK_PROD T2 ON T1.PROD_ID = T2.ROW_ID
    JOIN LNK_PRICE_LIST T3 ON T1.HEAD_ID = T3.ROW_ID
    JOIN REL_CRM_AE_ORG O ON T3.DEPT_ID = O.CRM_ORG_ID
  WHERE O.AE_ORG_CODE = :deptCode
    AND T3.CURRENCY = :currency
  ORDER BY T2.PROD_CODE;
  ```

### 常见问题

- 问题1：经销商用户为什么看不到"价目表名称"列？
  - 原因：前端根据用户类型（userType='D'）隐藏价目表名称列，经销商仅能看到价格数据，不知道具体价目表来源
  - 解决思路：如需查看价目表名称，联系内部用户查询

- 问题2：经销商用户为什么不能选择币种？
  - 原因：经销商用户的币种由其客商信息自动决定，前端隐藏币种查询条件
  - 解决思路：如需更改币种，修改经销商客商（LNK_ACCNT）的currency字段

- 问题3：导出按钮为什么不显示？
  - 原因：导出按钮需要权限hzero.crm.price.list.export，前端通过checkPermissions异步校验
  - 解决思路：联系管理员分配导出权限

- 问题4：瓷砖产品的库存数为什么不等于原始库存数？
  - 原因：瓷砖产品（LH_PROD_LINE='CeramicTile'）的库存数按计费单位与基本单位的转换率换算，展示值=Round(原始库存数/转换率, 2)
  - 解决思路：查看转换率字段确认换算比例

- 问题5：海外事业部经销商查询人民币价目表时为什么看到的价格和其他经销商不同？
  - 原因：海外事业部+CNY场景下，系统根据经销商的出口标识（exportType）匹配不同价目表：出口客户匹配"海外事业部价目表_CNY（出口）"，非出口客户匹配"海外事业部价目表"
  - 解决思路：检查经销商客商的outAccount字段确认出口标识
