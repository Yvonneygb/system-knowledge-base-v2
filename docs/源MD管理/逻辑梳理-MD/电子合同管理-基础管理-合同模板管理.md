# 电子合同管理-基础管理-合同模板管理

> 后端代码位于 mbo-business 微服务，API 路径前缀为 `ch/contract/template/*`。

## 业务流程

```
用户进入合同模板管理页面
        |
        ├── 新建模板 ──→ 跳转详情页 ──→ 录入模板信息 ──→ 上传模板文件 ──→ 保存
        |
        ├── 编辑模板 ──→ 跳转详情页 ──→ 加载详情 ──→ 修改 ──→ 保存
        |
        ├── 查看详情 ──→ 跳转详情页(只读)
        |
        └── 删除模板 ──→ 确认删除 ──→ 删除成功
```

模板类型和子模板类型通过接口动态加载，关联公司通过 query-relation-company/list 接口查询。

### 上游依赖

| 上游模块 | 依赖类型 | 依赖说明 | 依赖成立条件 |
|---------|---------|---------|-------------|
| 值集管理 MBO.CONTRACT_TEMPLATE | 数据依赖 | 提供模板类型下拉选项 | 值集已配置 |
| 值集管理 MBO.CONTRACT_SUB_TEMPLATE | 数据依赖 | 经销合同子类型选项 | 值集已配置 |
| 值集管理 MBO.HARDWARE_SUB_TYPE | 数据依赖 | 装修协议子类型选项 | 值集已配置 |
| 值集管理 MBO.ADVERTISING_SUB_TYPE | 数据依赖 | 广告协议子类型选项 | 值集已配置 |
| 关联公司查询 | 接口依赖 | 提供授权单位下拉选项 | 接口可用 |
| OSS 对象存储 | 接口依赖 | 模板文件存储 | OSS 服务可用 |

### 下游影响

- 合同签署时引用已生效的模板生成电子合同
- 授权书组件通过模板类型拉取模板列表
- 合同通用配置通过子模板类型拉取子模板列表

## 重点逻辑

### 重点逻辑1：模板类型驱动显隐

- **业务意义**：不同模板类型需要配置不同字段，动态显隐减少无效字段干扰
- **具体逻辑描述**：模板类型决定页面字段显隐，授权书类型显示更换授权单位勾选框与授权单位下拉；经销合同/装修协议/广告协议类型显示模板子类型；授权书/承诺函类型显示模板变量表格

### 重点逻辑2：模板子类型动态值集

- **业务意义**：子类型选项随模板类型变化，确保选项与类型匹配
- **具体逻辑描述**：模板子类型的 lookupCode 根据模板类型动态切换：经销合同→MBO.CONTRACT_SUB_TEMPLATE，装修协议→MBO.HARDWARE_SUB_TYPE，广告协议→MBO.ADVERTISING_SUB_TYPE

### 重点逻辑3：文件上传校验

- **业务意义**：确保模板文件格式和大小符合要求
- **具体逻辑描述**：单个文件不超过30MB，仅支持 doc/docx 格式，上传成功后将 fileUrl/createUserName/fileType 写入附件DataSet，上传失败时弹出错误提示

### 重点逻辑4：变量维护

- **业务意义**：模板变量用于合同生成时替换占位符
- **具体逻辑描述**：模板变量表格可动态增删行，每行包含模板中变量和模板中变量名称两个字段，均必填，提交时通过 varReqDtoList 传给后端

### 重点逻辑5：提交校验顺序

- **业务意义**：确保提交数据完整性，按顺序校验避免遗漏
- **具体逻辑描述**：先校验基础表单 baseFormDS.validate()，再校验变量表 variableTableDS.validate()，最后校验模板文件是否已上传，任一不通过则中断提交

#### 按钮1：确认（详情页头部按钮，新增/编辑模式）

新增/编辑模式显示"确认"按钮，调用 `handleSubmit`：
1. `baseFormDS.validate()` 校验基础表单（模板名称、模板类型、模板子类型、授权单位等必填字段）
2. `variableTableDS.validate()` 校验模板变量表格（每行变量名、变量名称非空）
3. 校验 `templateFile?.fileUrl` 是否存在，若为空则提示"请上传合同模板文件"
4. 组装数据：`{ ...baseFormDS.current.toData(), varReqDtoList: templateVariableList, fileDTO: templateFile }`
5. 调用 `contractTemplateApi.add`（POST `ch/contract/template/add`）或 `contractTemplateApi.edit`（POST `ch/contract/template/edit`）接口
6. 成功后关闭当前Tab

#### 按钮2：编辑（详情页头部按钮，详情模式）

详情模式显示"编辑"按钮，调用 `handleEdit`：
1. `closeTab(getActiveTabKey())` 关闭当前Tab
2. `openTab({ title: '编辑合同模板', key: '/contract/template/edit/${id}' })` 打开编辑页面

#### 按钮3：增加变量（详情页，变量表格上方）

非详情模式显示，调用 `handleAddVariable`：`variableTableDS.create({})` 在变量DataSet新建空行。

#### 按钮4：删除变量（变量表格行操作）

非详情模式显示，调用 `handleRemoveVariable`：`variableTableDS.remove(record)` 从变量DataSet移除当前行。

#### 按钮5：下载（附件表格行操作）

调用 `handleDownloadTemplate`：`window.open(fileUrl)` 新窗口打开模板文件。

#### 按钮6：删除附件（附件表格行操作）

非详情模式显示，调用 `handleRemoveTemplate`：`record && dataSet.delete(record).then(() => setTemplateFile(null))` 从附件DataSet删除并清空 templateFile。

### 保存/提交校验

- 校验1：模板名称非空 —— 确保模板有唯一标识名称
- 校验2：模板类型非空 —— 确保模板分类明确
- 校验3：模板子类型非空(经销合同/装修协议/广告协议时) —— 确保子分类与类型匹配
- 校验4：授权单位非空(更换授权单位=Y时) —— 确保授权主体明确
- 校验5：模板变量每行变量名/变量名称非空(变量表格显示时) —— 确保变量配置完整
- 校验6：模板文件 fileUrl 必须存在 —— 确保模板文件已上传
- 校验7：文件大小不超过30MB —— 确保文件大小合规
- 校验8：文件格式为 doc/docx —— 确保文件格式合规

### 状态机

```
[新建] --保存--> [未生效(NOT_ENABLE)] --启用--> [已生效(ENABLE)]
                                          --停用--> [未生效(NOT_ENABLE)]

[已生效(ENABLE)] --停用--> [未生效(NOT_ENABLE)] --启用--> [已生效(ENABLE)]
```

| 状态 | 状态说明 | 可执行操作 |
|------|---------|-----------|
| 未生效(NOT_ENABLE) | 模板未启用 | 编辑、启用、删除 |
| 已生效(ENABLE) | 模板已启用 | 编辑、停用 |

查询SQL：

```sql
SELECT T.ELECTRONIC_CONTRACT_TEMPLATE_CODE AS "模板编码",
       T.ELECTRONIC_CONTRACT_TEMPLATE_NAME AS "模板名称",
       T.TEMPLATE_TYPE                     AS "模板类型",
       T.TEMPLATE_SUBTYPE                  AS "子模板类型",
       T.AUTHORIZED_COMPANY                AS "关联公司",
       T.TEMPLATE_STATUS                   AS "状态",
       T.CREATION_DATE                     AS "创建时间",
       T.LAST_UPDATE_DATE                  AS "更新时间"
FROM ELECTRONIC_CONTRACT_TEMPLATE T
WHERE (:templateName IS NULL OR T.ELECTRONIC_CONTRACT_TEMPLATE_NAME LIKE '%' || :templateName || '%')
  AND (:templateCode IS NULL OR T.ELECTRONIC_CONTRACT_TEMPLATE_CODE LIKE '%' || :templateCode || '%')
  AND (:templateType IS NULL OR T.TEMPLATE_TYPE = :templateType)
  AND (:templateSubtype IS NULL OR T.TEMPLATE_SUBTYPE = :templateSubtype)
  AND (:templateStatus IS NULL OR T.TEMPLATE_STATUS = :templateStatus)
ORDER BY T.CREATION_DATE DESC;
```

## 常见问题FAQ

### 报错一览表

| 报错信息 | 提示节点 | 根因与解决方案 | 等级 | 详细逻辑 |
|---------|---------|--------------|------|---------|
| 模板名称不能为空 | 保存时 | 未输入模板名称，输入模板名称 | error | 前端校验模板名称非空 |
| 模板类型不能为空 | 保存时 | 未选择模板类型，选择模板类型 | error | 前端校验模板类型非空 |
| 模板子类型不能为空 | 保存时 | 经销合同/装修协议/广告协议未选子类型，选择模板子类型 | error | 前端校验子类型非空 |
| 授权单位不能为空 | 保存时 | 更换授权单位=Y但未选授权单位，选择授权单位 | error | 前端校验授权单位非空 |
| 请上传合同模板文件 | 保存时 | 未上传模板文件，上传docx模板文件 | error | 前端校验fileUrl存在 |
| 单个文件不能大于30MB | 上传时 | 文件超过30MB，压缩或更换文件 | error | 前端校验文件大小 |
| 上传失败 | 上传时 | OSS服务异常或文件格式不支持，检查网络与文件格式 | error | OSS上传接口返回失败 |
| 模板已被引用，不可删除 | 删除时 | 有合同引用了该模板，禁用而非删除 | error | 后端校验模板引用关系 |
| 网络异常/接口超时 | 任意接口调用 | 网络中断或接口响应超时，检查网络及后端超时配置 | error | axios catch 或 timeout |
| 权限不足 | 点击操作按钮 | 当前用户无对应按钮权限码，联系管理员授权 | error | permissionList 校验未通过 |
| 模板不存在 | 编辑/删除/生效 | 模板编码不存在或已删除，检查 TEMPLATE_CODE 有效性 | error | 接口返回数据为空 |
| 状态不允许操作 | 生效/失效 | 模板状态不允许该操作，如已生效不可重复生效，检查 TEMPLATE_STATUS | error | 后端校验状态机失败 |
| 值集数据不显示 | 下拉选项 | 值集 MBO.CONTRACT_TEMPLATE 等未配置，检查值集配置 | warning | lookupCode 查询返回空 |
| 模板编码已存在 | 新建保存 | 模板编码重复，更换编码后保存 | error | 后端校验 TEMPLATE_CODE 唯一性 |

#### 报错5：请上传合同模板文件
- **触发条件**：保存模板时，模板文件 fileUrl 不存在
- **逻辑分析**：前端提交前校验模板文件是否已上传，若 fileUrl 为空则阻止提交并提示"请上传合同模板文件"。模板文件是合同生成的核心依据，必须上传
- **排查SQL**：
  ```sql
  SELECT t.ELECTRONIC_CONTRACT_TEMPLATE_CODE AS 模板编码,
         t.ELECTRONIC_CONTRACT_TEMPLATE_NAME AS 模板名称,
         t.TEMPLATE_STATUS AS 状态,
         f.FILE_NAME AS 文件名称,
         f.FILE_URL AS 文件地址
  FROM ELECTRONIC_CONTRACT_TEMPLATE t
  LEFT JOIN ELECTRONIC_CONTRACT_TEMPLATE_FILE f
    ON t.ELECTRONIC_CONTRACT_TEMPLATE_ID = f.TEMPLATE_ID
  WHERE t.TEMPLATE_STATUS IN ('ENABLE', 'NOT_ENABLE')
    AND (f.FILE_URL IS NULL OR f.FILE_URL = '');
  ```

#### 报错6：单个文件不能大于30MB
- **触发条件**：上传模板文件时，文件大小超过30MB
- **逻辑分析**：前端上传组件对文件大小配置 maxSize=30MB 校验，上传前校验文件大小，超过30MB则阻止上传并提示"单个文件不能大于30MB"。限制文件大小避免OSS存储压力和上传超时
- **排查SQL**：
  ```sql
  SELECT FILE_ID AS 文件ID,
         TEMPLATE_ID AS 模板ID,
         FILE_NAME AS 文件名称,
         FILE_URL AS 文件地址,
         FILE_TYPE AS 文件类型
  FROM ELECTRONIC_CONTRACT_TEMPLATE_FILE
  WHERE FILE_NAME IS NOT NULL
    AND LENGTH(FILE_NAME) > 100;
  ```

#### 报错7：上传失败
- **触发条件**：上传模板文件时，OSS服务异常或文件格式不支持
- **逻辑分析**：前端调用OSS上传接口，若OSS服务不可用、网络异常、文件格式非 doc/docx、文件损坏等则上传失败，提示"上传失败"。需检查OSS服务连通性、网络、文件格式、文件完整性
- **排查SQL**：
  ```sql
  SELECT FILE_ID AS 文件ID,
         TEMPLATE_ID AS 模板ID,
         FILE_NAME AS 文件名称,
         FILE_URL AS 文件地址,
         FILE_TYPE AS 文件类型,
         CREATE_USER_NAME AS 上传人,
         TO_CHAR(CREATION_DATE,'YYYY-MM-DD HH24:MI:SS') AS 上传时间
  FROM ELECTRONIC_CONTRACT_TEMPLATE_FILE
  WHERE FILE_URL IS NULL OR FILE_URL = ''
     OR FILE_TYPE NOT IN ('doc', 'docx');
  ```

#### 报错8：模板已被引用，不可删除
- **触发条件**：删除模板时，有合同引用了该模板
- **逻辑分析**：后端校验模板引用关系，查询 ELECTRONIC_CONTRACT 表中引用该模板的合同记录，若存在引用则提示"模板已被引用，不可删除"。已引用的模板删除会导致合同生成异常，需先禁用模板（设置为 NOT_ENABLE 状态）而非删除
- **排查SQL**：
  ```sql
  SELECT t.ELECTRONIC_CONTRACT_TEMPLATE_CODE AS 模板编码,
         t.ELECTRONIC_CONTRACT_TEMPLATE_NAME AS 模板名称,
         t.TEMPLATE_STATUS AS 状态,
         COUNT(c.ELECTRONIC_CONTRACT_ID) AS 引用合同数
  FROM ELECTRONIC_CONTRACT_TEMPLATE t
  LEFT JOIN ELECTRONIC_CONTRACT c
    ON t.ELECTRONIC_CONTRACT_TEMPLATE_ID = c.TEMPLATE_ID
  GROUP BY t.ELECTRONIC_CONTRACT_TEMPLATE_CODE,
           t.ELECTRONIC_CONTRACT_TEMPLATE_NAME,
           t.TEMPLATE_STATUS
  HAVING COUNT(c.ELECTRONIC_CONTRACT_ID) > 0;
  ```

#### 报错9：网络异常/接口超时
- **触发条件**：任意接口调用时，网络中断或接口响应超过 axios timeout 配置
- **逻辑分析**：前端 axios 请求未收到响应或响应超时，触发 catch 回调统一提示"请求失败"。常见根因：网络中断、mbo-business 服务假死、数据库慢查询、OSS服务响应慢等。需检查网络连通性、后端服务负载、OSS服务状态
- **排查SQL**：
  ```sql
  SELECT ELECTRONIC_CONTRACT_TEMPLATE_CODE AS 模板编码,
         ELECTRONIC_CONTRACT_TEMPLATE_NAME AS 模板名称,
         TEMPLATE_STATUS AS 状态,
         TO_CHAR(LAST_UPDATE_DATE,'YYYY-MM-DD HH24:MI:SS') AS 最后更新时间
  FROM ELECTRONIC_CONTRACT_TEMPLATE
  WHERE LAST_UPDATE_DATE >= SYSDATE - 1
  ORDER BY LAST_UPDATE_DATE DESC;
  ```

#### 报错10：权限不足
- **触发条件**：点击新建、编辑、删除、生效/失效等按钮时，当前用户无对应 permissionList 权限码
- **逻辑分析**：前端 Button 组件通过 permissionList 配置权限码，HZERO 框架校验当前用户角色是否包含该权限码，未包含则按钮不可见或禁用。若强制调用接口，后端也会校验权限返回403。需联系管理员配置对应角色权限
- **排查SQL**：
  ```sql
  SELECT U.USER_NAME AS 用户名, R.ROLE_NAME AS 角色名, P.PERMISSION_CODE AS 权限码
  FROM SYS_USER U
  LEFT JOIN SYS_USER_ROLE UR ON U.USER_ID = UR.USER_ID
  LEFT JOIN SYS_ROLE R ON UR.ROLE_ID = R.ROLE_ID
  LEFT JOIN SYS_ROLE_PERMISSION RP ON R.ROLE_ID = RP.ROLE_ID
  LEFT JOIN SYS_PERMISSION P ON RP.PERMISSION_ID = P.PERMISSION_ID
  WHERE P.PERMISSION_CODE LIKE '%contract_template%' ORDER BY U.USER_NAME;
  ```

#### 报错11：模板不存在
- **触发条件**：编辑、删除、生效/失效等操作时，接口返回数据为空或模板编码不存在
- **逻辑分析**：前端通过 templateCode 调用详情接口，后端查询 ELECTRONIC_CONTRACT_TEMPLATE 表无对应记录或记录已逻辑删除，返回空数据。常见根因：模板编码错误、模板已被删除、跨租户查询、数据权限隔离等。需检查 TEMPLATE_CODE 有效性及数据权限
- **排查SQL**：
  ```sql
  SELECT ELECTRONIC_CONTRACT_TEMPLATE_CODE AS 模板编码,
         ELECTRONIC_CONTRACT_TEMPLATE_NAME AS 模板名称,
         TEMPLATE_STATUS AS 状态, DELETE_FLAG AS 删除标记
  FROM ELECTRONIC_CONTRACT_TEMPLATE
  WHERE DELETE_FLAG = 'Y' OR ELECTRONIC_CONTRACT_TEMPLATE_CODE IS NULL;
  ```

#### 报错12：状态不允许操作
- **触发条件**：点击生效/失效按钮时，模板状态不允许该操作
- **逻辑分析**：后端校验状态机，如已生效（ENABLE）不可重复生效、已失效（NOT_ENABLE）不可重复失效等。状态不匹配时后端返回业务异常。需检查模板当前状态及操作流程
- **排查SQL**：
  ```sql
  SELECT ELECTRONIC_CONTRACT_TEMPLATE_CODE AS 模板编码,
         ELECTRONIC_CONTRACT_TEMPLATE_NAME AS 模板名称,
         TEMPLATE_STATUS AS 状态, ERROR_INFO AS 异常问题
  FROM ELECTRONIC_CONTRACT_TEMPLATE
  WHERE TEMPLATE_STATUS NOT IN ('ENABLE','NOT_ENABLE')
  ORDER BY CREATE_DATE DESC;
  ```

#### 报错13：值集数据不显示
- **触发条件**：查询条件或列表中模板类型等下拉选项为空
- **逻辑分析**：前端通过 lookupCode 查询值集 MBO.CONTRACT_TEMPLATE、MBO.CONTRACT_TEMPLATE_SUBTYPE 等，值集未配置或未启用则下拉选项为空。需在值集管理页面配置对应值集
- **排查SQL**：
  ```sql
  SELECT LOOKUP_CODE AS 值集编码, LOOKUP_VALUE_CODE AS 值编码,
         LOOKUP_VALUE_NAME AS 值名称, ENABLE_FLAG AS 启用标记
  FROM SYS_LOOKUP_VALUE
  WHERE LOOKUP_CODE IN ('MBO.CONTRACT_TEMPLATE','MBO.CONTRACT_TEMPLATE_SUBTYPE')
    AND ENABLE_FLAG = 'N' ORDER BY LOOKUP_CODE;
  ```

#### 报错14：模板编码已存在
- **触发条件**：新建模板保存时，ELECTRONIC_CONTRACT_TEMPLATE_CODE 已存在于 ELECTRONIC_CONTRACT_TEMPLATE 表
- **逻辑分析**：后端校验 ELECTRONIC_CONTRACT_TEMPLATE_CODE 唯一性，若已存在则返回业务异常。需更换模板编码后保存
- **排查SQL**：
  ```sql
  SELECT ELECTRONIC_CONTRACT_TEMPLATE_CODE AS 模板编码, COUNT(*) AS 重复数
  FROM ELECTRONIC_CONTRACT_TEMPLATE
  WHERE DELETE_FLAG = 'N'
  GROUP BY ELECTRONIC_CONTRACT_TEMPLATE_CODE
  HAVING COUNT(*) > 1;
  ```

### 常见问题

| 问题 | 排查方式 |
|------|---------|
| 模板变量表格不显示 | 仅当模板类型为授权书或承诺函时显示变量表格，其他类型不显示 |
| 模板无法被合同签署引用 | 检查模板状态是否为已生效，未生效模板不可引用 |
| 更换授权单位勾选框不显示 | 仅当模板类型为授权书时显示该勾选框 |
| 上传文件后附件表格未刷新 | 检查OSS返回的fileUrl是否存在，若为空会触发上传失败提示 |
| 禁用模板后已引用合同受影响吗 | 不会，已创建的合同保留引用时的模板快照 |
| 模板类型下拉为空 | 检查值集 MBO.CONTRACT_TEMPLATE 是否配置 |
| 子类型下拉为空 | 检查对应子类型值集是否配置(MBO.CONTRACT_SUB_TEMPLATE等) |
| 授权单位下拉为空 | 检查 ch/contract/query-relation-company/list 接口返回数据 |
