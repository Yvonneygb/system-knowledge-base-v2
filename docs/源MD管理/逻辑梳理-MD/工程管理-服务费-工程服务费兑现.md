# 工程管理-服务费-工程服务费兑现

> **说明**：本菜单为低代码页面（hlod），前端无独立页面源码，通过低代码平台配置绑定后端接口渲染。后端Controller为EpmExpenseToCashController，API路径/v1/{orgId}/epm-expense-to-cash。

---

## 业务流程

### 业务流程图

```text
开始 → ★新建服务费兑现★ → 选择项目/合同 → 填写兑现信息 → 保存 → 提交审批 → ⚖审批通过？
  ├─（通过）兑现完成 → 财务处理 → 结束
  └─（拒绝）可修改后重新提交 → 结束
```

### 上游依赖

| 上游模块 | 依赖类型 | 依赖说明 | 依赖成立条件 |
|---------|---------|---------|------------|
| 项目主档 | 数据依赖 | 选择工程项目 | 项目已创建 |
| 合同主档 | 数据依赖 | 关联合同 | 合同已签订 |
| 服务费预提数据 | 数据依赖 | 兑现关联预提数据 | 预提已存在 |
| OA工作流引擎 | 服务依赖 | 提交审批触发工作流 | 工作流已配置 |
| 低代码平台 | 配置依赖 | 页面通过低代码配置渲染 | 配置已完成 |

### 下游影响

- 影响1：财务处理
  - 兑现审批通过后进入财务付款流程

#### 报错1：兑现单不存在
- **触发条件**：查询工程服务费兑现单详情时，按CASH_NO查询EPM_SERVICE_FEE_CASH返回null
- **逻辑分析**：详情方法中按CASH_NO查询兑现单，若返回null则抛出阻断性报错。需检查兑现单号有效性
- **排查SQL**：
  ```sql
  SELECT esfc.CASH_ID, esfc.CASH_NO, esfc.PROJECT_CODE, esfc.CONTRACT_CODE, esfc.HZ_APPROVE_STATUS
  FROM EPM_SERVICE_FEE_CASH esfc
  WHERE esfc.CASH_NO = :cashNo
  -- 若返回空，说明兑现单不存在
  ```

#### 报错2：兑现金额超过可兑现金额
- **触发条件**：提交工程服务费兑现申请时，兑现金额超过剩余可兑现金额
- **逻辑分析**：提交校验中按PROJECT_CODE和CONTRACT_CODE查询剩余可兑现金额(已认领服务费-已兑现金额)，若本次兑现金额>剩余则抛出阻断性报错。需调整兑现金额
- **排查SQL**：
  ```sql
  SELECT esfc.CASH_ID, esfc.CASH_NO, esfc.CASH_AMOUNT, esfc.PROJECT_CODE, esfc.CONTRACT_CODE,
         esfc.TOTAL_SERVICE_FEE, esfc.CASHED_AMOUNT,
         esfc.TOTAL_SERVICE_FEE - esfc.CASHED_AMOUNT AS 剩余可兑现金额
  FROM EPM_SERVICE_FEE_CASH esfc
  WHERE esfc.CASH_NO = :cashNo
  -- 对比兑现金额与剩余可兑现金额
  ```
