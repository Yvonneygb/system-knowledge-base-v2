## 业务流程

### 业务流程图

```text
用户在产品图片上传页面操作
        │
        ▼
  选择产品编码 + 图片类型 + 上传图片文件
        │
        ▼
  HZERO文件上传服务（fileClient.uploadAttachment）
        │
        ├─── 上传至OSS（bucketName + storageCode + directoryCustom）
        │
        ▼
  生成文件URL（HFLE_FILE.file_url）
        │
        ▼
  写入OBJ_FILE_BUS_REL（relBusType=prod, busType=prodPhoto, busId=产品编码, fileUrl=文件URL）
        │
        ▼
  产品图册查询页面可查看新上传的图片
```

### 上游依赖

| 上游模块 | 依赖类型 | 依赖说明 | 依赖成立条件 |
|---------|---------|---------|------------|
| LNK_PROD（产品主数据表） | 数据依赖 | 上传图片时需指定产品编码，产品需存在 | 产品已创建 |
| OBJ_FILE_TYPE（文件类型表） | 数据依赖 | 定义图片分类类型（busType=prodPhoto） | 文件类型已配置 |
| HFLE文件服务 | 服务依赖 | 文件上传至OSS并生成文件URL | OSS配置正确 |
| 值集（LOV） | 配置依赖 | 图片类型字段依赖值集CRM.OBJ_FILE_TYPE（busType=prodPhoto） | 值集已配置 |

### 下游影响

- 影响1：产品图册
  - 上传的图片在产品图册查询页面和产品详情页图册Tab中展示

- 影响2：产品变更申请
  - 产品变更申请图册变更行可引用已上传的图片

## 重点逻辑

### 重点逻辑1：文件上传至OSS `文件存储`

- **业务意义**：产品图片存储在OSS对象存储中，确保高可用和CDN加速

- **具体逻辑描述**

  - 第1点：通过HZERO文件客户端fileClient.uploadAttachment上传文件至OSS

  - 第2点：上传参数包括bucketName（存储桶）、directoryCustom（目录）、uuid（唯一标识）、fileName（文件名）、fileType（文件类型）、storageCode（存储编码）

  - 第3点：上传成功后返回文件URL，用于后续关联记录写入

### 重点逻辑2：导入批量处理 `批量导入`

- **业务意义**：支持通过Excel模板批量导入产品图片关联关系

- **具体逻辑描述**

  - 第1点：导入模板编码CRM.PROD_PHOTO，导入处理类ProdPhotoImport

  - 第2点：ProdPhotoImport继承ObjFileBusRelImportServiceImpl，固定busType=prodPhoto、relBusType=prod

  - 第3点：导入数据解析为busId（产品编码）、fileUrl（文件URL）、fileType（文件类型）

  - 第4点：批量调用objFileBusRelService.saveData写入OBJ_FILE_BUS_REL表

## 详细逻辑

### 界面模块1：产品图片上传页

> 本页面为低代码页面（hlod），无独立前端路由和源码。使用HZERO平台标准文件上传组件，后端通过ProdPhotoImport（模板CRM.PROD_PHOTO）处理导入，数据写入OBJ_FILE_BUS_REL表。

| 字段名 | 数据库列名 | 组件 | 业务释义 | 显隐条件 | 取值/赋值逻辑 |

### 导入

#### 前置约定

- 文件格式：Excel（.xlsx）
- 模板编码：CRM.PROD_PHOTO
- 导入处理类：ProdPhotoImport（busType=prodPhoto, relBusType=prod）
- 权限：hzero.product_data.product_info.product_list.ps.import

#### 字段映射

| 字段含义 | 是否必输 | 字段格式 | 重复判定字段 |
|---------|---------|---------|------------|
| 产品编码（busId） | 是 | 文本 | 是（同产品+同类型） |
| 文件URL（fileUrl） | 是 | 文本/URL | 否 |
| 文件类型（fileType） | 是 | 文本 | 否 |

#### 处理逻辑

- **校验逻辑**：由HZERO导入框架按模板配置校验
- **导入逻辑**：
  - 第1点：解析导入数据为busId、fileUrl、fileType
  - 第2点：调用objFileBusRelService.getFileBusRel构建ObjFileBusRel实体（fileBusType=prodPhoto, relBusType=prod）
  - 第3点：批量调用objFileBusRelService.saveData写入OBJ_FILE_BUS_REL表
- **重复处理策略**：按模板配置
- **性能方案**：批量插入

#### 异常与结果约定

- 部分成功/失败时的处理：由导入框架控制，支持失败明细导出
- 结果反馈机制：导入完成后提示成功/失败数量

#### 运维保障

- 日志记录：HZERO导入框架自动记录导入日志
- 断点续传/重试机制：支持失败行重新导入


#### 报错2：产品编码不存在
- **触发条件**：保存图片关联关系时，校验输入的产品编码在LNK_PROD表中不存在
- **逻辑分析**：后端保存OBJ_FILE_BUS_REL记录前，先查询LNK_PROD表确认产品编码存在。若产品编码拼写错误、产品已被删除或产品尚未同步入库，则校验失败抛出异常。
- **排查SQL**：
  ```sql
  SELECT P.PROD_CODE AS 产品编码, P.PROD_NAME AS 产品名称,
         P.PROD_STATUS AS 上下架状态, P.SM_STATE AS 生命状态
  FROM LNK_PROD P
  WHERE P.PROD_CODE = :prodCode;
  -- 若查询结果为空，确认产品编码不存在或已删除
  ```

#### 报错3：文件类型不存在:prodPhoto:xxx
- **触发条件**：通过Excel导入产品图片时，导入的图片类型在OBJ_FILE_TYPE表中不存在
- **逻辑分析**：后端ObjFileBusRelServiceImpl.getFileBusRel方法根据fileBusType=prodPhoto和fileType查询OBJ_FILE_TYPE表（status=1），若objFileTypeDb为null则抛出RuntimeException。导入处理类ProdPhotoImport继承ObjFileBusRelImportServiceImpl，固定busType=prodPhoto、relBusType=prod。常见于导入模板的图片类型值与系统配置不一致。
- **排查SQL**：
  ```sql
  SELECT T.ID, T.BUS_TYPE, T.FILE_BUS_TYPE, T.FILE_BUS_TYPE_NAME, T.STATUS
  FROM OBJ_FILE_TYPE T
  WHERE T.BUS_TYPE = 'prodPhoto' AND T.STATUS = '1'
  ORDER BY T.FILE_BUS_TYPE;
  -- 若查询结果不含导入的fileType值，则需在OBJ_FILE_TYPE表中新增配置
  ```

#### 报错4：产品编码必填
- **触发条件**：保存或导入时，未填写产品编码（busId）字段
- **逻辑分析**：产品编码为OBJ_FILE_BUS_REL.BUS_ID字段，对应界面"产品编码"必填项。前端表单校验或导入框架按模板CRM.PROD_PHOTO配置校验，若为空则阻断保存。产品编码需关联LNK_PROD.PROD_CODE，确保图片关联到有效产品。
- **排查SQL**：
  ```sql
  SELECT COUNT(1) AS 产品存在数
  FROM LNK_PROD P
  WHERE P.PROD_CODE = :busId;
  -- 若:busId为空或查询结果为0，则校验失败
  ```

#### 报错5：图片类型必填
- **触发条件**：保存或导入时，未选择图片类型（fileType）字段
- **逻辑分析**：图片类型对应OBJ_FILE_TYPE.FILE_BUS_TYPE，界面为下拉选择框，来源值集CRM.OBJ_FILE_TYPE（busType=prodPhoto）。前端表单校验或导入框架按模板配置校验，若为空则阻断保存。图片类型需在OBJ_FILE_TYPE表中存在且busType=prodPhoto、status=1。
- **排查SQL**：
  ```sql
  SELECT T.FILE_BUS_TYPE AS 类型编码, T.FILE_BUS_TYPE_NAME AS 类型名称
  FROM OBJ_FILE_TYPE T
  WHERE T.BUS_TYPE = 'prodPhoto' AND T.STATUS = '1';
  -- 若未选择图片类型或选择的值不在上述结果中，则校验失败
  ```

#### 报错6：导入失败
- **触发条件**：通过Excel模板CRM.PROD_PHOTO导入产品图片时，导入框架校验失败或批量写入OBJ_FILE_BUS_REL异常
- **逻辑分析**：导入由HZERO导入框架处理，ProdPhotoImport.doImport方法解析每行数据为busId、fileUrl、fileType，调用getFileBusRel构建ObjFileBusRel实体，再批量调用saveData写入数据库。任一行校验失败（如文件类型不存在、产品编码为空）或数据库写入异常均导致导入失败，支持失败明细导出。
- **排查SQL**：
  ```sql
  -- 检查导入的图片关联数据
  SELECT F.BUS_ID AS 产品编码, F.FILE_URL AS 文件URL, F.FILE_TYPE_ID AS 文件类型ID,
         F.SOURCE AS 来源, F.CREATION_DATE AS 创建时间
  FROM OBJ_FILE_BUS_REL F
  WHERE F.REL_BUS_TYPE = 'prod'
    AND F.SOURCE = 'IMPORT'
    AND F.CREATION_DATE >= SYSDATE - 1
  ORDER BY F.CREATION_DATE DESC;
  ```

#### 报错7：权限不足
- **触发条件**：用户执行产品图片导入操作时，当前用户无对应权限
- **逻辑分析**：产品图片上传页为低代码页面，导入操作需权限hzero.product_data.product_info.product_list.ps.import。若用户无权限则接口返回403或导入按钮不显示。常见于用户角色未分配产品图片导入权限。
- **排查SQL**：
  ```sql
  SELECT R.ROLE_CODE, R.ROLE_NAME, P.PERMISSION_CODE, P.DESCRIPTION
  FROM HZERO.IAM_ROLE R
    JOIN HZERO.IAM_ROLE_PERMISSION RP ON R.ID = RP.ROLE_ID
    JOIN HZERO.IAM_PERMISSION P ON RP.PERMISSION_ID = P.ID
  WHERE P.PERMISSION_CODE LIKE '%product_list.ps.import%'
    AND R.ROLE_CODE = :currentRoleCode;
  ```

#### 报错8：会话过期
- **触发条件**：用户在产品图片上传页面操作时，登录会话（access_token）已过期
- **逻辑分析**：前端请求携带的access_token过期，后端返回401未授权。前端HZERO框架拦截401状态码跳转登录页。常见于长时间未操作页面或token有效期过短。
- **排查SQL**：
  ```sql
  -- 无直接SQL，检查用户会话状态
  SELECT U.LOGIN_NAME, U.LAST_LOGIN_DATE AS 最后登录时间
  FROM HZERO.IAM_USER U
  WHERE U.LOGIN_NAME = :currentLoginName;
  ```

### 常见问题

- 问题1：上传后图片在图册页面看不到
  - 原因：OBJ_FILE_BUS_REL记录的REL_BUS_TYPE或BUS_TYPE不正确，或FILE_TYPE_ID未正确关联
  - 解决思路：
    ```sql
    SELECT F.*, T.FILE_BUS_TYPE, T.FILE_BUS_TYPE_NAME
    FROM OBJ_FILE_BUS_REL F
      LEFT JOIN OBJ_FILE_TYPE T ON F.FILE_TYPE_ID = T.ID
    WHERE F.REL_BUS_TYPE = 'prod' AND F.BUS_ID = :prodCode;
    ```

- 问题2：导入失败提示文件类型不存在
  - 原因：OBJ_FILE_TYPE表中未配置对应的busType=prodPhoto的文件类型
  - 解决思路：在OBJ_FILE_TYPE表中添加对应的文件类型配置
