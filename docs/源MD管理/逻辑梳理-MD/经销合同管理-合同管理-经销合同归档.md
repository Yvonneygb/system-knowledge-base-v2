# 经销合同管理-合同管理-经销合同归档

> **注意**：本菜单与"经销合同管理-销售合同-年度经销合同"共用同一套后端代码（SaSaleContractHeadController/SaSaleContractHead），归档是年度经销合同的子功能，通过工作流SA_SALE_CONTRACT_HEAD_GD区分。

## 业务流程

### 业务流程图

```text
经销合同归档页面
        │
        ├── 查询待归档合同 ──→ GET /sa-sale-contract-heads/search
        │
        ├── 保存并提交归档 ──→ POST /sa-sale-contract-heads/saveAndSubmit
        │                       └── 发起归档审批流程(SA_SALE_CONTRACT_HEAD_GD)
        │                             ├── 审批通过 ──→ 更新归档状态为已归档
        │                             └── 审批拒绝 ──→ 保持未归档
        │
        └── 归档判断 ──→ judgeContractArchive（自动判断是否满足归档条件）
```

### 上游依赖

| 上游模块 | 依赖类型 | 依赖说明 | 依赖成立条件 |
|---------|---------|---------|------------|
| 年度经销合同 | 数据依赖 | 归档对象为已审批通过的年度经销合同 | 合同已审批通过 |
| OA审批系统 | 服务依赖 | 归档需经OA审批 | OA系统可用 |

### 下游影响

- 影响1：合同状态
  - 归档后合同状态变为已归档，不可再修改

- 影响2：合同变更
  - 已归档合同需通过变更流程修改

## 重点逻辑

### 重点逻辑1：归档条件判断 {归档校验}

- **业务意义**：合同需满足特定条件才能归档，确保归档合规

- **具体逻辑描述**

  - 第1点：通过judgeContractArchive方法判断合同是否满足归档条件

  - 第2点：校验合同是否已审批通过、任务是否已完成等条件

  - 第3点：满足条件后通过addContractArchivePushTask创建归档推送任务

### 重点逻辑2：归档工作流 {审批流转}

- **业务意义**：归档需经OA审批，确保归档操作合规

- **具体逻辑描述**

  - 第1点：通过saveAndSubmit发起归档审批流程(SA_SALE_CONTRACT_HEAD_GD)

  - 第2点：审批通过后更新归档状态(statePigeonhole)、实际归档时间(actualPigeonholeDate)、归档人(pigeonholeBy)

## 常见问题FAQ

### 报错一览表

| 报错信息 | 提示节点 | 根因与解决方案 | 等级 | 详细逻辑 |
|---------|---------|-------------|------|---------|
| 合同不满足归档条件 | 归档提交时 | 合同未审批通过或任务未完成，先完成前置条件 | 阻断性报错 | [查看] |
| 未配置经销合同延期归档天数 | 归档推送时 | 系统参数CONTRACT_PIGEONHOLE_DATE未配置，联系管理员 | 阻断性报错 | [查看] |
| 该合同应归档日期为空 | 归档推送时 | 合同PIGEONHOLE_DATE为空，重新计算归档日期 | 阻断性报错 | [查看] |
| 添加合同归档推送任务异常 | 归档推送时 | 推送任务合同数据为空，重新发起归档 | 阻断性报错 | [查看] |
| 流程编码缺失 | 归档提交时 | 未选择归档审批流程，选择流程后提交 | 阻断性报错 | [查看] |
| 查询原合同归档时间失败 | 归档变更时 | 原合同应归档时间/实际归档时间查询失败，核对数据 | 阻断性报错 | [查看] |

#### 报错1：合同不满足归档条件
- **触发条件**：用户选中合同点击"归档提交"，judgeContractArchive方法校验不通过
- **逻辑分析**：归档条件校验通过judgeContractArchive方法判断，本菜单与菜单115共用SA_SALE_CONTRACT_HEAD表，归档通过工作流SA_SALE_CONTRACT_HEAD_GD区分。不满足条件根因有三类：(1)合同未审批通过（HZ_APPROVE_STATUS != 'APPROVED'），归档要求合同先完成年度经销合同审批（DISTRIBUTION_CONTRACT_DKHB流程）；(2)合同任务未完成，如合同任务完成率未达标或存在未结清的保证金/认缴；(3)合同已归档（STATE_PIGEONHOLE已为已归档），重复归档被拦截。此为阻断性报错，需先完成前置条件再提交归档
- **排查SQL**：
  ```sql
  SELECT SALE_CONTRACT_HEAD_ID, CONTRACT_NO, CUSTOMER_NAME, CONTRACT_YEAR,
         HZ_APPROVE_STATUS, STATE_PIGEONHOLE, PIGEONHOLE_DATE, ACTUAL_PIGEONHOLE_DATE
  FROM SA_SALE_CONTRACT_HEAD
  WHERE SALE_CONTRACT_HEAD_ID = #{id}
    AND (HZ_APPROVE_STATUS != 'APPROVED' OR STATE_PIGEONHOLE IS NOT NULL);
  ```

#### 报错2：未配置经销合同延期归档天数
- **触发条件**：归档推送CRM时，scpSysConf查询CONTRACT_PIGEONHOLE_DATE系统参数返回空
- **逻辑分析**：SaSaleContractHeadServiceImpl.insertPigeonholeDate方法通过scpSysConf(SysConfConstants.CONTRACT_PIGEONHOLE_DATE)获取归档天数，用于计算应归档日期（PIGEONHOLE_DATE=START_DATE+归档天数）。系统参数未配置时无法计算归档日期，导致后续归档推送和延期判断失败。需联系管理员在系统参数配置中补全CONTRACT_PIGEONHOLE_DATE
- **排查SQL**：
  ```sql
  SELECT PARAM_CODE, PARAM_VALUE FROM SYS_CONFIG
  WHERE PARAM_CODE = 'Contract_Pigeonhole_date';
  ```

#### 报错3：该合同应归档日期为空
- **触发条件**：归档模块调用CRM接口时，saSaleContractHead.getPigeonholeDate()返回null
- **逻辑分析**：SaSaleContractHeadServiceImpl归档CRM接口调用时校验PIGEONHOLE_DATE非空，为空时抛IllegalArgumentException。根因是该合同为历史数据（功能上线前签订），未通过insertPigeonholeDate自动生成归档日期。需手动补全PIGEONHOLE_DATE或重新触发归档日期计算
- **排查SQL**：
  ```sql
  SELECT SALE_CONTRACT_HEAD_ID, CONTRACT_NO, START_DATE, PIGEONHOLE_DATE, STATE_PIGEONHOLE
  FROM SA_SALE_CONTRACT_HEAD
  WHERE SALE_CONTRACT_HEAD_ID = #{id} AND PIGEONHOLE_DATE IS NULL;
  ```

#### 报错4：添加合同归档推送任务异常
- **触发条件**：归档推送任务创建时，saleContractDto合同数据为空
- **逻辑分析**：SaSaleContractHeadServiceImpl添加归档推送任务方法校验saleContractDto非空，为空时抛CommonException。根因是归档推送任务队列消息体缺失合同数据，可能由消息序列化异常或上游传参错误导致。需重新发起归档流程生成完整推送任务
- **排查SQL**：
  ```sql
  SELECT SALE_CONTRACT_HEAD_ID, CONTRACT_NO, STATE_PIGEONHOLE, PIGEONHOLE_DATE_REALLY
  FROM SA_SALE_CONTRACT_HEAD
  WHERE SALE_CONTRACT_HEAD_ID = #{id} AND (CONTRACT_NO IS NULL OR CONTRACT_NO = '');
  ```

#### 报错5：流程编码缺失
- **触发条件**：用户点击"保存并提交"发起归档审批，dto.getFlowCode()为空
- **逻辑分析**：SaSaleContractHeadServiceImpl.saveAndSubmit方法首行校验flowCode非空，归档需通过工作流SA_SALE_CONTRACT_HEAD_GD审批，flowCode为空无法启动工作流。根因是前端未选择归档审批流程或流程配置缺失。需在提交前选择归档审批流程
- **排查SQL**：
  ```sql
  SELECT WORKFLOW_CODE, WORKFLOW_NAME FROM WORKFLOW_CONFIG
  WHERE WORKFLOW_CODE = 'SA_SALE_CONTRACT_HEAD_GD';
  ```

#### 报错6：查询原合同归档时间失败
- **触发条件**：合同变更时查询原合同的应归档时间、实际归档时间、延迟发货日期，查询结果异常
- **逻辑分析**：SaSaleContractHeadServiceImpl变更方法查询原合同PIGEONHOLE_DATE、PIGEONHOLE_DATE_REALLY、延期发货日期，查询失败时抛CommonException。根因是原合同数据不完整或已被删除，导致变更时无法继承归档信息。需核对原合同数据完整性
- **排查SQL**：
  ```sql
  SELECT SALE_CONTRACT_HEAD_ID, CONTRACT_NO, PIGEONHOLE_DATE,
         PIGEONHOLE_DATE_REALLY, DELIVER_DELAY_DATE
  FROM SA_SALE_CONTRACT_HEAD
  WHERE SA_CONTR_HEAD_CODE = #{saContrHeadCode};
  ```
