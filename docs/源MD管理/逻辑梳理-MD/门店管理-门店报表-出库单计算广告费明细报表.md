# 门店管理-门店报表-出库单计算广告费明细报表

> 本页面为低代码页面(hlod)，无独立前端源码，基于后端API梳理。

## 业务流程

出库单计算广告费明细报表用于查询出库单中每个产品的广告费计算明细。报表关联出库接口头表、出库接口确认表、订单应收关联表等，展示经销商、出库单号、产品信息、发货日期、签收日期、开票金额、广告费计提比例、广告金额等明细数据。本页面为纯查询报表，仅支持查看和导出，不支持新增、修改、删除等写操作。

**核心流程：**
1. 用户进入出库单计算广告费明细报表页面
2. 填写查询条件（经销商、出库单号、是否计广告费、发货日期范围、签收日期范围等）
3. 点击查询，调用后端接口分页返回出库单广告费明细数据
4. 用户查看报表数据，可导出Excel归档

```
开始 → 设定查询条件 → 点击查询 → 后端查询INV_OUT_BILL_INTF_HEAD等7表关联 → 排除特殊物料 → 计算开票金额/实际结算金额/广告金额 → 返回明细数据 → 查看报表/导出Excel → 结束
```

- 上游支撑：出库接口头表（INV_OUT_BILL_INTF_HEAD）、出库接口确认表（INV_OUT_BILL_INTF_CONFIRM）、订单应收关联（LNK_OB_ORDER_RECEIVABLE）、客户（CUSTOMER）、事业部基础设置（DIVISION_BASE_SET）、物料（ITEM/ITEM_ORG）、hlod报表引擎
- 下游影响：广告费计算明细核对、出库单广告费统计、Excel导出归档、内部管理决策参考

## 重点逻辑

### 重点逻辑1：纯报表查询页面【只读查询】

- **业务意义**：供内部人员查询出库单中每个产品的广告费计算明细，了解广告费的计提情况
- **具体逻辑描述**：
  - 本页面为hlod低代码报表页面，无独立前端源码
  - 仅提供查询和导出功能，不支持新增、修改、删除操作
  - 数据来源于7张表关联查询，包含出库单、产品、签收、经销商等信息

### 重点逻辑2：广告费计算逻辑

- **业务意义**：根据是否计广告费标志和广告费计提比例，计算每行产品的广告金额
- **具体逻辑描述**：
  - 开票金额（discount_Amount）= ROUND(折后单价 × 实发数量, 2) = ROUND(DEALER_PARICE × SALES_REAL_QUANTITY, 2)
  - 实际结算金额（pay_Amount）= 开票金额 + 扣除广告费金额 + 不计广告费金额 = discount_Amount + DEDUCT_CASHPOOL_AMOUNT + EXCLUDE_CASHPOOL_AMOUNT
  - 广告金额（adver_Amount）= CASE WHEN ADVERTISING_FLAG='Y' THEN (开票金额 + 扣除广告费金额) × 广告费计提比例 ELSE 0 END
  - 即：adver_Amount = CASE WHEN ADVERTISING_FLAG='Y' THEN (discount_Amount + DEDUCT_CASHPOOL_AMOUNT) × ADVERTISING_FEE ELSE 0 END

### 重点逻辑3：排除特殊物料

- **业务意义**：排除资金池和提价两类特殊物料，确保报表只展示正常产品
- **具体逻辑描述**：
  - SQL中固定过滤条件：`hh.item_number NOT IN ('CUX_OM_CASH_POOL', 'CUX_OM_PRICE_RAISE')`
  - CUX_OM_CASH_POOL：资金池物料
  - CUX_OM_PRICE_RAISE：提价物料

### 重点逻辑4：多表关联查询

- **业务意义**：通过7张表关联获取完整的出库单广告费明细
- **具体逻辑描述**：
  - INV_OUT_BILL_INTF_HEAD h：出库接口头表，提供出库单号、经销商、发货日期、广告费计提比例等
  - INV_OUT_BILL_INTF_CONFIRM l：出库接口确认表，提供产品明细、实发数量、折后单价等
  - LNK_OB_ORDER_RECEIVABLE o：订单应收关联表，提供确认签收日期（gl_date）
  - CUSTOMER c：客户表，关联经销商
  - DIVISION_BASE_SET r：事业部基础设置，提供组织ID
  - ITEM i / ITEM_ORG io：物料表，提供产品型号

### 重点逻辑5：查询条件匹配规则

- **业务意义**：支持多维度灵活筛选出库单广告费明细数据
- **具体逻辑描述**：
  - 模糊查询（LIKE '%xxx%'）：经销商名称、ERP出库单号
  - 精确查询：经销商编码、是否计广告费、组织ID
  - 范围查询：发货日期范围（deliveryDateStart/deliveryDateEnd）、确认签收日期范围（glDateStart/glDateEnd）
  - 日期格式：YYYY-MM-DD HH24:MI:SS

### 后端接口Mapper SQL

```sql
-- 出库单计算广告费明细报表查询
SELECT * FROM (
    SELECT
        h.SERVICE_NUMBER,
        h.SERVICE_NAME,
        h.DELIVERY_NUMBER,
        h.DELIVERY_DATE,
        h.SELL_CHANNEL,
        o.gl_date,
        l.item_number,
        l.product_name,
        io.item_model,
        l.ADVERTISING_FLAG,
        l.SALES_UOM_CODE,
        l.SALES_REAL_QUANTITY,
        l.DEALER_PARICE AS DEALER_PRICE,
        l.DEDUCT_CASHPOOL_AMOUNT,
        l.EXCLUDE_CASHPOOL_AMOUNT,
        ROUND(dealer_parice * sales_real_quantity, 2) AS discount_Amount,
        (ROUND(dealer_parice * sales_real_quantity, 2) + l.DEDUCT_CASHPOOL_AMOUNT + l.EXCLUDE_CASHPOOL_AMOUNT) AS pay_Amount,
        h.ADVERTISING_FEE,
        CASE l.advertising_flag
            WHEN 'Y' THEN ((ROUND(dealer_parice * sales_real_quantity, 2) + l.DEDUCT_CASHPOOL_AMOUNT) * h.ADVERTISING_FEE)
            ELSE 0
        END AS adver_Amount,
        h.DELIVERY_OU_NAME,
        h.INVOICE_PARTY,
        h.INVOICE_PARTY_NUMBER,
        h.BUSINESS_DIVISION,
        r.organization_id
    FROM inv_out_bill_intf_head h
    INNER JOIN inv_out_bill_intf_confirm l ON h.delivery_id = l.delivery_id
    INNER JOIN lnk_ob_order_receivable o ON o.delivery_line_id = l.delivery_line_id
    INNER JOIN customer c ON c.customer_code = h.service_number
    INNER JOIN DIVISION_BASE_SET r ON r.DIVISION_NAME = h.business_division
    LEFT JOIN item i ON i.item_code = l.item_number
    LEFT JOIN item_org io ON io.item_id = i.item_id
) hh
WHERE 1 = 1
    AND hh.item_number NOT IN ('CUX_OM_CASH_POOL', 'CUX_OM_PRICE_RAISE')  -- 排除资金池和提价物料
    AND hh.organization_id = #{param.orgId}                               -- 组织ID（精确）
    AND hh.service_name LIKE '%' || #{param.serviceName} || '%'           -- 经销商名称（模糊）
    AND hh.service_number = #{param.serviceNumber}                        -- 经销商编码（精确）
    AND hh.delivery_number LIKE '%' || #{param.deliveryNumber} || '%'     -- ERP出库单号（模糊）
    AND hh.advertising_flag = #{param.advertisingFlag}                    -- 是否计广告费（精确）
    AND hh.delivery_date BETWEEN TO_DATE(#{param.deliveryDateStart}, 'YYYY-MM-DD HH24:MI:SS')
                              AND TO_DATE(#{param.deliveryDateEnd}, 'YYYY-MM-DD HH24:MI:SS')  -- 发货日期范围
    AND hh.gl_date BETWEEN TO_DATE(#{param.glDateStart}, 'YYYY-MM-DD HH24:MI:SS')
                        AND TO_DATE(#{param.glDateEnd}, 'YYYY-MM-DD HH24:MI:SS')              -- 签收日期范围
```

#### 报错1：查询结果为空
- **触发条件**：点击"查询"按钮，按当前查询条件（经销商、出库单号、是否计广告费、发货日期范围、签收日期范围等）关联查询INV_OUT_BILL_INTF_HEAD等7张表返回空结果集
- **逻辑分析**：报表关联出库接口头表（INV_OUT_BILL_INTF_HEAD）、出库接口确认表（INV_OUT_BILL_INTF_CONFIRM）、订单应收关联表（LNK_OB_ORDER_RECEIVABLE）等7张表，并排除物料编码为'CUX_OM_CASH_POOL'和'CUX_OM_PRICE_RAISE'的特殊物料。若查询条件过严、或出库单未签收（LNK_OB_ORDER_RECEIVABLE无关联记录）、或物料全部为特殊物料被排除、或经销商编码不匹配，均会返回空结果。该报错为提示性。
- **排查SQL**：
  ```sql
  SELECT h.delivery_number      AS 出库单号,
         h.cust_code            AS 经销商编码,
         h.delivery_date        AS 发货日期,
         o.gl_date              AS 签收日期,
         l.item_number          AS 产品编码,
         l.advertising_flag     AS 是否计广告费
  FROM   inv_out_bill_intf_head h
  LEFT   JOIN inv_out_bill_intf_confirm l ON h.delivery_id = l.delivery_id
  LEFT   JOIN lnk_ob_order_receivable o ON l.delivery_line_id = o.delivery_line_id
  WHERE  h.organization_id = #{当前用户组织ID}
  AND    l.item_number NOT IN ('CUX_OM_CASH_POOL', 'CUX_OM_PRICE_RAISE')
  ORDER  BY h.delivery_date DESC;
  ```

#### 报错2：日期格式错误
- **触发条件**：点击"查询"按钮，发货日期或签收日期参数传入TO_DATE转换时格式不匹配，Oracle抛出ORA-01861或类似异常
- **逻辑分析**：报表查询按发货日期范围（deliveryDateStart/deliveryDateEnd）和签收日期范围（glDateStart/glDateEnd）筛选，SQL中使用 `TO_DATE(#{date}, 'YYYY-MM-DD HH24:MI:SS')` 转换字符串为日期。若前端传入格式非YYYY-MM-DD HH24:MI:SS（如传入YYYY/MM/DD、带毫秒、或空字符串），TO_DATE转换失败抛出Oracle异常，查询中断。常见根因：前端日期选择器异常、手工拼接参数格式错误。
- **排查SQL**：
  ```sql
  SELECT delivery_id          AS 出库单ID,
         delivery_number      AS 出库单号,
         delivery_date        AS 发货日期,
         create_time          AS 创建时间
  FROM   inv_out_bill_intf_head
  WHERE  delivery_date IS NOT NULL
  ORDER  BY delivery_date DESC;
  ```

#### 报错3：网络请求失败/接口调用异常
- **触发条件**：点击"查询"或"导出"按钮，调用POST /v1/{organizationId}/rebate-details/mktOutBillHead/search或GET /mktOutBillHead/export接口时，前端未收到响应或收到非2xx状态码（如500、502、504）
- **逻辑分析**：本页面为hlod低代码报表页面，查询依赖后端RebateDetailsController接口分页查询INV_OUT_BILL_INTF_HEAD等7张表关联数据。若后端ae-business服务未启动、Oracle数据库连接异常、7表关联JOIN导致慢SQL、TO_DATE转换失败抛出ORA-01861、网络中断、或网关转发失败，均会导致接口调用异常。需检查后端服务健康状态、数据库连接、网络连通性。
- **排查SQL**：
  ```sql
  SELECT COUNT(*)            AS 出库单总数,
         MIN(delivery_date)  AS 最早发货日期,
         MAX(delivery_date)  AS 最晚发货日期
  FROM   inv_out_bill_intf_head;
  ```

#### 报错4：权限不足/未登录
- **触发条件**：页面加载或点击"查询"/"导出"按钮时，接口返回401未授权或403禁止访问，或前端路由守卫拦截
- **逻辑分析**：本报表接口为组织级权限接口，要求用户具备组织级权限。若用户未登录（token过期/丢失）、或当前角色未分配该报表菜单权限、或organizationId路径参数与用户所属组织不匹配，均会触发权限校验失败。hlod低代码页面通过路由配置和接口权限双重校验，任一环节失败均阻断访问。需重新登录或联系管理员分配报表查看权限。
- **排查SQL**：
  ```sql
  SELECT '权限校验为应用层逻辑，无对应数据表' AS 提示
  FROM   dual;
  ```

#### 报错5：导出失败：网络异常
- **触发条件**：点击"导出"按钮，调用GET /v1/{organizationId}/rebate-details/mktOutBillHead/export接口过程中，网络中断、后端响应超时或Excel文件流传输中断
- **逻辑分析**：导出接口通过@ProcessLovValue注解翻译是否计广告费字段（LOV_CODE='AE.YESNO'），后端先全量查询7表关联数据再通过SaOutBillHeadConvert转换生成Excel文件流返回。若查询数据量较大导致响应超时、或生成Excel过程中内存溢出、或网络不稳定导致文件流中断、或浏览器下载被拦截，均会触发导出失败。需重试导出或缩小查询条件（如限定发货日期范围、经销商）减少数据量。
- **排查SQL**：
  ```sql
  SELECT TO_CHAR(delivery_date, 'YYYY') AS 年度,
         COUNT(*)                       AS 出库单数量
  FROM   inv_out_bill_intf_head
  GROUP  BY TO_CHAR(delivery_date, 'YYYY')
  ORDER  BY 年度 DESC;
  ```

## 常见问题FAQ

**Q1：广告金额如何计算？**
A：当ADVERTISING_FLAG='Y'时，广告金额 = (开票金额 + 扣除广告费金额) × 广告费计提比例；当ADVERTISING_FLAG='N'时，广告金额=0。其中开票金额 = ROUND(折后单价 × 实发数量, 2)。

**Q2：报表排除了哪些物料？**
A：排除了物料编码为'CUX_OM_CASH_POOL'（资金池）和'CUX_OM_PRICE_RAISE'（提价）的特殊物料。

**Q3：报表数据来源是什么？**
A：数据来源于7张表关联查询：INV_OUT_BILL_INTF_HEAD（出库头）、INV_OUT_BILL_INTF_CONFIRM（出库确认）、LNK_OB_ORDER_RECEIVABLE（订单应收）、CUSTOMER（客户）、DIVISION_BASE_SET（事业部）、ITEM（物料）、ITEM_ORG（物料组织）。

**Q4：报表是否支持导出？**
A：是，支持导出Excel，标题为"出库单计算广告费明细报表"，导出时是否计广告费字段通过LOV(AE.YESNO)翻译。

**Q5：报表是否支持新增/修改/删除？**
A：不支持，本页面为纯查询报表，仅支持查看和导出。
