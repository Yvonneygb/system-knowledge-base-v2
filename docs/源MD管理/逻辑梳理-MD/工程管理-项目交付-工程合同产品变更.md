# 工程管理-项目交付-工程合同产品变更

---

## 业务流程

### 业务流程图

```text
开始 → ★新建合同产品变更★ → 选择项目/合同 → 选择变更产品 → 填写变更信息 → 保存 → 提交审批 → ⚖审批通过？
  ├─（通过）产品变更生效 → 更新合同产品 → 结束
 % └─（拒绝）可修改后重新提交 → 结束
```

### 上游依赖

| 上游模块 | 依赖类型 | 依赖说明 | 依赖成立条件 |
|---------|---------|---------|------------|
| 项目主档 | 数据依赖 | 选择工程项目 | 项目已创建 |
| 合同主档 | 数据依赖 | 选择需变更的合同 | 合同已签订 |
| 产品主档 | 数据依赖 | 选择变更产品 | 产品已维护 |
| OA工作流引擎 | 服务依赖 | 提交审批触发工作流 | 工作流已配置 |

### 下游影响

- 影响1：合同产品明细
  - 审批通过后更新合同的产品明细信息

---

## 重点逻辑

### 重点逻辑1：ECN变更单管理 `变更管理`

- **业务意义**：通过ECN工程变更单流程管理合同产品变更，保留变更记录

- **具体逻辑描述**

  - 第1点：使用EpmDiscountEcnController管理折扣ECN变更单

  - 第2点：API路径/v1/{orgId}/epm-discount-ecns

  - 第3点：与工程折扣延期共用后端Controller，通过单据类型区分

#### 报错1：折扣单号不能为空
- **触发条件**：保存工程合同产品变更单时，未选择折扣单(DISCOUNT_APPLY_OBJ为空)
- **逻辑分析**：保存校验中检查DISCOUNT_APPLY_OBJ非空，因变更必须关联原折扣单。需选择折扣单后保存
- **排查SQL**：
  ```sql
  SELECT edec.DISCOUNT_ECN_ID, edec.DISCOUNT_ECN_CODE, edec.DISCOUNT_APPLY_OBJ,
         edec.DISCOUNT_APPLY_CODE, edec.HZ_APPROVE_STATUS
  FROM EPM_DISCOUNT_ECN edec
  WHERE edec.DISCOUNT_ECN_ID = :discountEcnId
    AND (edec.DISCOUNT_APPLY_OBJ IS NULL OR edec.DISCOUNT_APPLY_OBJ = 0)
  -- 查出折扣单号为空的变更单
  ```

#### 报错2：变更说明不能为空
- **触发条件**：保存工程合同产品变更单时，变更说明(ECN_REASON)为空
- **逻辑分析**：保存校验中检查ECN_REASON非空，因变更说明记录变更原因。需填写变更说明后保存
- **排查SQL**：
  ```sql
  SELECT edec.DISCOUNT_ECN_ID, edec.DISCOUNT_ECN_CODE, edec.ECN_REASON, edec.HZ_APPROVE_STATUS
  FROM EPM_DISCOUNT_ECN edec
  WHERE edec.DISCOUNT_ECN_ID = :discountEcnId
    AND (edec.ECN_REASON IS NULL OR TRIM(edec.ECN_REASON) = '')
  -- 查出变更说明为空的变更单
  ```
