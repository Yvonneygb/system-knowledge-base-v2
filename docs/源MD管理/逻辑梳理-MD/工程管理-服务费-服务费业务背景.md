#### 报错1：背景编码不能为空
- **触发条件**：保存服务费业务背景时，背景编码字段为空
- **逻辑分析**：保存校验中检查背景编码非空，因背景编码为业务背景的唯一标识。需填写背景编码后保存
- **排查SQL**：
  ```sql
  SELECT esfb.BG_ID, esfb.BG_CODE, esfb.BG_NAME, esfb.BG_DESC
  FROM EPM_SERVICE_FEE_BG esfb
  WHERE esfb.BG_CODE IS NULL OR TRIM(esfb.BG_CODE) = ''
  -- 查出背景编码为空的异常数据
  ```

#### 报错2：背景名称不能为空
- **触发条件**：保存服务费业务背景时，背景名称字段为空
- **逻辑分析**：保存校验中检查背景名称非空，因背景名称为业务背景的显示名称。需填写背景名称后保存
- **排查SQL**：
  ```sql
  SELECT esfb.BG_ID, esfb.BG_CODE, esfb.BG_NAME, esfb.BG_DESC
  FROM EPM_SERVICE_FEE_BG esfb
  WHERE esfb.BG_NAME IS NULL OR TRIM(esfb.BG_NAME) = ''
  -- 查出背景名称为空的异常数据
  ```

#### 报错3：背景编码已存在
- **触发条件**：保存服务费业务背景时，背景编码已存在其他记录
- **逻辑分析**：保存校验中按BG_CODE查询EPM_SERVICE_FEE_BG，若存在(排除当前记录)则抛出阻断性报错。需修改为唯一编码
- **排查SQL**：
  ```sql
  SELECT esfb.BG_ID, esfb.BG_CODE, esfb.BG_NAME
  FROM EPM_SERVICE_FEE_BG esfb
  WHERE esfb.BG_CODE = :bgCode
    AND esfb.BG_ID <> :currentBgId
  -- 查出背景编码重复的记录
  ```

#### 报错4：请选择一条数据
- **触发条件**：在列表页未选中任何行即点击"删除"或"编辑"按钮
- **逻辑分析**：前端按钮事件中校验列表选中行数，若selectedRecords.length=0则弹出提示。需先选中一条数据再操作
- **排查SQL**：
  ```sql
  -- 前端校验，无对应SQL
  SELECT esfb.BG_ID, esfb.BG_CODE, esfb.BG_NAME
  FROM EPM_SERVICE_FEE_BG esfb
  WHERE esfb.BG_ID = :selectedBgId
  -- 校验选中行是否存在
  ```

#### 报错5：请求失败，请稍后重试
- **触发条件**：任意操作时后端服务异常或网络中断
- **逻辑分析**：前端axios请求捕获异常后统一弹出，可能原因：后端服务未启动、数据库连接异常、网络中断。稍后重试，仍失败需联系IT排查后端日志
- **排查SQL**：
  ```sql
  -- 系统级错误，检查后端服务状态
  SELECT COUNT(*) AS 服务费背景总数 FROM EPM_SERVICE_FEE_BG esfb
  -- 校验数据库连接是否正常
  ```

#### 报错6：权限不足
- **触发条件**：当前用户无该菜单访问权限或操作权限
- **逻辑分析**：低代码平台权限校验中检查用户角色是否包含该菜单权限编码，若无则抛出阻断性报错。需联系管理员分配对应权限
- **排查SQL**：
  ```sql
  SELECT iu.USER_ID, iu.LOGIN_NAME, iur.ROLE_ID, ir.ROLE_NAME
  FROM IAM_USER iu
  JOIN IAM_USER_ROLE iur ON iu.USER_ID = iur.USER_ID
  JOIN IAM_ROLE ir ON iur.ROLE_ID = ir.ROLE_ID
  WHERE iu.USER_ID = :currentUserId
  -- 查出当前用户角色，确认是否包含服务费背景维护权限
  ```

#### 报错7：操作失败，数据已被其他用户修改
- **触发条件**：编辑保存时，该记录已被其他用户并发修改，OBJECT_VERSION_NUMBER不一致
- **逻辑分析**：乐观锁校验中检查OBJECT_VERSION_NUMBER，若与编辑时获取的版本号不一致则抛出阻断性报错。需刷新数据后重新编辑
- **排查SQL**：
  ```sql
  SELECT esfb.BG_ID, esfb.BG_CODE, esfb.BG_NAME,
         esfb.OBJECT_VERSION_NUMBER, esfb.LAST_UPDATE_DATE, esfb.LAST_UPDATED_BY
  FROM EPM_SERVICE_FEE_BG esfb
  WHERE esfb.BG_ID = :bgId
  -- 对比OBJECT_VERSION_NUMBER判断是否被并发修改
  ```
