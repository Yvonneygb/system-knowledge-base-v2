# 门店管理-门店报表-门店统计分析

> 本页面为低代码页面(hlod)，无独立前端源码，基于后端API梳理。

## 业务流程

门店统计分析报表用于按经销商维度统计门店的多维度分布数据，包括运营状态（运营中/撤店）、经营属性（直营专营/经销专营/分销）、门店等级（一线/地级/县级）、门店类型（专卖/商超/家装/社区/乡镇）、门店面积（<=100/100-200/200-300/>300平米）、装修风格（按事业部entid区分A6/V9/V10/F1/F11/A7UP/A7等）、连锁属性、系统归属（DMG/红星美凯龙/华美立家/居然之家/欧亚达/银座/月星/其他）等。数据来源于客户表（CUSTOMER）关联客户组织表（CUSTOMER_ORG），通过大量子查询统计MKT_TERMINAL表中各维度的门店数量。本页面为纯查询报表，仅支持查看和导出，不支持新增、修改、删除等写操作。

**核心流程：**
1. 用户进入门店统计分析报表页面
2. 填写查询条件（事业部、销售区域、运营中心、省份、城市、经销商等）
3. 点击查询，调用后端接口分页返回门店统计分析数据
4. 用户查看报表数据，可导出Excel归档（标题"终端分布报表"）

```
开始 → 设定查询条件 → 点击查询 → 后端查询CUSTOMER+CUSTOMER_ORG → 大量子查询统计MKT_TERMINAL各维度数量 → 返回统计数据 → 查看报表/导出Excel → 结束
```

- 上游支撑：客户表（CUSTOMER）、客户组织表（CUSTOMER_ORG）、门店表（MKT_TERMINAL）、事业部基础设置（DIVISION_BASE_SET）、hlod报表引擎
- 下游影响：门店多维度分布分析、经销商门店统计、Excel导出归档、内部管理决策参考

## 重点逻辑

### 重点逻辑1：纯报表查询页面【只读查询】

- **业务意义**：供内部人员按经销商维度查看门店的多维度统计分布数据
- **具体逻辑描述**：
  - 本页面为hlod低代码报表页面，无独立前端源码
  - 仅提供查询和导出功能，不支持新增、修改、删除操作
  - 数据来源于客户表关联客户组织表，通过大量子查询统计门店各维度数量

### 重点逻辑2：多维度子查询统计

- **业务意义**：通过50+个子查询，按经销商维度统计门店的各维度数量
- **具体逻辑描述**：
  - 运营状态：yunying(terminal_stat=1)、chedian(terminal_stat=2)
  - 经营属性：zbzy(customer_class=1)、jxzy(customer_class=2)、fx(customer_class=3)
  - 门店等级：level1/2/3(store_area_level='1'/'2'/'3')
  - 门店类型：dian1~5(terminal_type=1~5)
  - 门店面积：area1(<=100)、area2(100-200)、area3(200-300)、area4(>300)
  - 装修风格：按entid(101~109)和decoration_style(1~3)交叉统计
  - 连锁：is_ls(is_ls=2)
  - 系统归属：dmg/hxmkl/hmlj/jrzj/oyd/yzjj/yxjj/other(sys_id=1~8)
  - 每个子查询格式：`(SELECT COUNT(...) FROM epms.mkt_terminal t WHERE t.cust_id = c.customer_id AND t.某字段 = 某值 GROUP BY t.某字段)`

### 重点逻辑3：装修风格按事业部区分

- **业务意义**：不同事业部（entid）的装修风格编码含义不同，需分别统计
- **具体逻辑描述**：
  - entid=101：decoration_style=1(A6)、2(其他)
  - entid=102：decoration_style=1(V9)、2(V10)、3(其他)
  - entid=103：decoration_style=1(F1)、2(其他)
  - entid=104：decoration_style=1(A6)、2(其他)
  - entid=105：decoration_style=1(F11)、2(F1)、3(其他)
  - entid=106：decoration_style=1(A7UP)、2(A7)、3(其他)
  - entid=107~109：decoration_style=1(其他)

### 重点逻辑4：导出Excel列定义

- **业务意义**：导出时按预定义的列顺序和标题输出Excel
- **具体逻辑描述**：
  - 导出标题："终端分布报表"
  - 使用@ExcelSheet和@ExcelColumn注解定义列顺序(order)和标题
  - 异步导出阈值：asyncThreshold = 10000（超过1万条异步导出）
  - 列顺序：事业部→经销商编码→经销商名称→省份→城市→区域→运营中心→运营→撤店→总部自营→经销自营→分销→一线及省会→地级市→县级→专卖→商超→家装→社区→乡镇→100平米以下→100~200→200~300→300以上→A6→其他→属于家具连锁→大明宫→红星美凯龙→华美立家→居然之家→欧亚达→银座家居→月星家居→其他

### 重点逻辑5：查询条件匹配规则

- **业务意义**：支持多维度灵活筛选门店统计数据
- **具体逻辑描述**：
  - 精确查询：组织ID、事业部ID、销售区域ID、运营中心ID、省份ID、城市ID、经销商编码
  - 经销商名称：未在SQL中作为查询条件（DTO中有但SQL未使用）
  - 必须存在门店：`WHERE EXISTS (SELECT 1 FROM epms.mkt_terminal t WHERE t.cust_id = a.customer_id)`

#### 报错1：查询结果为空
- **触发条件**：点击"查询"按钮，按当前查询条件（事业部、销售区域、运营中心、省份、城市、经销商等）查询CUSTOMER关联CUSTOMER_ORG返回空结果集
- **逻辑分析**：报表查询CUSTOMER关联CUSTOMER_ORG，并通过 `WHERE EXISTS (SELECT 1 FROM epms.mkt_terminal t WHERE t.cust_id = a.customer_id)` 筛选必须存在门店的经销商。若查询条件过严（如经销商编码拼写错误、事业部ID不匹配）、或经销商名下无门店（EXISTS条件不成立）、或用户组织ID与数据不匹配，均会返回空结果。该报错为提示性，不影响系统。
- **排查SQL**：
  ```sql
  SELECT c.customer_id        AS 客户ID,
         c.customer_code      AS 经销商编码,
         c.customer_name      AS 经销商名称,
         COUNT(t.terminal_id) AS 门店数量
  FROM   customer c
  LEFT   JOIN mkt_terminal t ON t.cust_id = c.customer_id
  WHERE  EXISTS (
           SELECT 1 FROM mkt_terminal t2
           WHERE t2.cust_id = c.customer_id
         )
  GROUP  BY c.customer_id, c.customer_code, c.customer_name
  ORDER  BY 门店数量 DESC;
  ```

#### 报错2：子查询返回多行
- **触发条件**：查询结果展示时，某经销商在某维度（如装修风格、门店面积等）的子查询 `(SELECT COUNT(...) FROM epms.mkt_terminal t WHERE t.cust_id = c.customer_id AND t.某字段 = 某值 GROUP BY t.某字段)` 返回多行
- **逻辑分析**：报表通过50+个子查询按经销商维度统计门店各维度数量，每个子查询格式为 `(SELECT COUNT(...) FROM epms.mkt_terminal t WHERE t.cust_id = c.customer_id AND t.某字段 = 某值 GROUP BY t.某字段)`。正常情况下GROUP BY后每个分组值仅返回一行，但若子查询的WHERE条件和GROUP BY字段不一致（如WHERE按terminal_stat筛选但GROUP BY按decoration_style分组）、或数据存在异常重复、或entid关联错误导致同一经销商门店跨事业部统计，子查询可能返回多行，Oracle抛出ORA-01427单行子查询返回多行错误，整条查询失败。
- **排查SQL**：
  ```sql
  SELECT t.cust_id           AS 客户ID,
         t.decoration_style  AS 装修风格,
         t.entid             AS 企业ID,
         COUNT(*)            AS 门店数量
  FROM   mkt_terminal t
  GROUP  BY t.cust_id, t.decoration_style, t.entid
  HAVING COUNT(DISTINCT t.entid) > 1
  ORDER  BY 门店数量 DESC;
  ```

#### 报错3：网络请求失败/接口调用异常
- **触发条件**：点击"查询"或"导出"按钮，调用POST /v1/{organizationId}/terminalReport/mkt-terminal-distribution/search或GET /mkt-terminal-distribution/export接口时，前端未收到响应或收到非2xx状态码（如500、502、504）
- **逻辑分析**：本页面为hlod低代码报表页面，查询依赖后端TerminalReportController.mktTerminalDistributionSearch接口分页查询CUSTOMER关联CUSTOMER_ORG，并通过50+个子查询统计MKT_TERMINAL各维度数量。若后端ae-report服务未启动、Oracle数据库连接异常、50+子查询导致严重慢SQL、子查询返回多行触发ORA-01427、网络中断、或网关转发失败，均会导致接口调用异常。因子查询数量多，该接口对数据库性能敏感。需检查后端服务健康状态、数据库连接、网络连通性。
- **排查SQL**：
  ```sql
  SELECT COUNT(*)            AS 客户总数,
         COUNT(t.terminal_id) AS 门店总数
  FROM   customer c
  LEFT   JOIN mkt_terminal t ON t.cust_id = c.customer_id
  WHERE  EXISTS (
           SELECT 1 FROM mkt_terminal t2
           WHERE t2.cust_id = c.customer_id
         );
  ```

#### 报错4：权限不足/未登录
- **触发条件**：页面加载或点击"查询"/"导出"按钮时，接口返回401未授权或403禁止访问，或前端路由守卫拦截
- **逻辑分析**：本报表接口声明@Permission(level = ResourceLevel.ORGANIZATION)，要求用户具备组织级权限。若用户未登录（token过期/丢失）、或当前角色未分配该报表菜单权限、或organizationId路径参数与用户所属组织不匹配，均会触发权限校验失败。hlod低代码页面通过路由配置和接口权限双重校验，任一环节失败均阻断访问。需重新登录或联系管理员分配报表查看权限。
- **排查SQL**：
  ```sql
  SELECT '权限校验为应用层逻辑，无对应数据表' AS 提示
  FROM   dual;
  ```

#### 报错5：导出失败：网络异常
- **触发条件**：点击"导出"按钮，调用GET /v1/{organizationId}/terminalReport/mkt-terminal-distribution/export接口过程中，网络中断、后端响应超时或Excel文件流传输中断
- **逻辑分析**：导出接口通过@ExcelExport(value = MktTerminalDistributionExportVO.class, asyncThreshold = 10000)注解实现Excel导出，超过1万条数据异步导出。后端先全量查询CUSTOMER关联CUSTOMER_ORG及50+子查询统计数据再生成Excel文件流返回。若查询数据量较大导致响应超时、或异步导出任务排队失败、或生成Excel过程中内存溢出、或网络不稳定导致文件流中断、或浏览器下载被拦截，均会触发导出失败。需重试导出或缩小查询条件（如限定事业部、销售区域）减少数据量。
- **排查SQL**：
  ```sql
  SELECT COUNT(*)            AS 有门店的经销商数量
  FROM   customer c
  WHERE  EXISTS (
           SELECT 1 FROM mkt_terminal t
           WHERE t.cust_id = c.customer_id
         );
  ```

## 常见问题FAQ

**Q1：报表统计哪些维度？**
A：统计运营状态（运营/撤店）、经营属性（直营/经销/分销）、门店等级（一线/地级/县级）、门店类型（专卖/商超/家装/社区/乡镇）、门店面积（4段）、装修风格（按事业部区分）、连锁属性、系统归属（8类）等维度。

**Q2：装修风格为什么按entid区分？**
A：不同事业部（entid=101~109）的装修风格编码含义不同。例如entid=101时decoration_style=1表示A6风格，entid=102时decoration_style=1表示V9风格。

**Q3：导出Excel的标题是什么？**
A：标题为"终端分布报表"，超过1万条数据时异步导出。

**Q4：报表是否支持新增/修改/删除？**
A：不支持，本页面为纯查询报表，仅支持查看和导出。
