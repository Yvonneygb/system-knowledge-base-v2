## 业务流程

### 业务流程图

```text
开始 → ★新建项目合同失效申请★ → 选择项目/合同 → 填写失效原因 → 保存 → 提交审批 → ⚖审批通过？
```

## 常见问题FAQ

### 报错一览表

| 报错信息 | 提示节点 | 根因与解决方案 | 等级 | 详细逻辑 |
|---------|---------|-------------|------|---------|
| 失效单不存在 | 查询详情时 | 按DISABLE_NO查询EPM_PROJECT_DISABLE为空。检查失效单号有效性 | 高 | [查看] |
| 合同已失效，不可重复失效 | 提交时 | 合同VALID=3(已失效)。无需重复操作 | 高 | [查看] |
| 仅新建状态单据允许删除 | 删除时 | 单据HZ_APPROVE_STATUS非NEW。仅新建状态可删除 | 高 | [查看] |
| 项目报备数据不存在 | 审批通过推送CRM时 | 按PROJECT_ID查询EPM_REPORT为空。检查项目报备数据完整性 | 高 | [查看] |

#### 报错1：失效单不存在
- **触发条件**：查询项目合同失效单详情时，按DISABLE_NO查询EPM_PROJECT_DISABLE返回null
- **逻辑分析**：详情方法中按DISABLE_NO查询失效单，若返回null则抛出阻断性报错。需检查失效单号有效性
- **排查SQL**：
  ```sql
  SELECT epd.DISABLE_ID, epd.DISABLE_NO, epd.PROJECT_CODE, epd.CONTRACT_CODE, epd.HZ_APPROVE_STATUS
  FROM EPM_PROJECT_DISABLE epd
  WHERE epd.DISABLE_NO = :disableNo
  -- 若返回空，说明失效单不存在
  ```

#### 报错2：合同已失效，不可重复失效
- **触发条件**：提交项目合同失效申请时，合同VALID=3(已失效)
- **逻辑分析**：提交校验中按CONTRACT_CODE查询EPM_PROJECT_CONTRACT，若VALID=3则抛出阻断性报错。无需重复操作
- **排查SQL**：
  ```sql
  SELECT epc.CONTRACT_ID, epc.CONTRACT_CODE, epc.CONTRACT_NAME, epc.VALID, epc.HZ_APPROVE_STATUS
  FROM EPM_PROJECT_CONTRACT epc
  WHERE epc.CONTRACT_CODE = :contractCode
    AND epc.VALID = 3
  -- 查出已失效的合同
  ```

#### 报错3：仅新建状态单据允许删除
- **触发条件**：删除项目合同失效单时，单据HZ_APPROVE_STATUS非NEW
- **逻辑分析**：删除方法中校验单据状态为NEW，其他状态(审批中/已通过/已拒绝)不允许删除。该报错为阻断性报错
- **排查SQL**：
  ```sql
  SELECT epd.DISABLE_ID, epd.DISABLE_NO, epd.HZ_APPROVE_STATUS, epd.VALID
  FROM EPM_PROJECT_DISABLE epd
  WHERE epd.DISABLE_ID = :disableId
  -- 期望 HZ_APPROVE_STATUS = 'NEW'
  ```

#### 报错4：项目报备数据不存在
- **触发条件**：项目合同失效审批通过后推送CRM时，按PROJECT_ID查询EPM_REPORT为空
- **逻辑分析**：在EpmProjectDisableServiceImpl审批回调方法中(line 133)，审批通过后按PROJECT_ID查询EPM_REPORT项目报备表，若返回空集合则抛出CommonException("项目报备数据不存在")。该报错发生在审批通过后的CRM推送环节，需检查项目报备数据是否完整
- **排查SQL**：
  ```sql
  SELECT epd.DISABLE_ID, epd.DISABLE_NO, epd.PROJECT_ID, epd.PROJECT_CODE,
         epd.HZ_APPROVE_STATUS,
         (SELECT COUNT(1) FROM EPM_REPORT er WHERE er.PROJECT_ID = epd.PROJECT_ID) AS 报备数据数
  FROM EPM_PROJECT_DISABLE epd
  WHERE epd.DISABLE_ID = :disableId
  -- 期望 报备数据数 > 0
  ```
