# 财务管理-预提与冲销-额度内冲销报表

## 业务流程

### 业务流程图

```text
额度内冲销报表页面(arrow-ae标准React页面)
        │
        ├── 查询冲销数据 ──→ 查询fin_fee_writeoff_in_quota表
        │                      └── Repository层: queryWriteoffInQuotaView, queryOffNewView,
        │                          queryHolding, queryBillStatus, queryQuotaLimitHead
        │
        ├── 更新冲销数据 ──→ POST /writeoff-in-quota/updateReversalData
        │
        └── 执行冲销 ──→ POST /writeoff-in-quota/execReversalData
                          └── 推送共享财务系统(ENCX-额度内冲销)
```

### 上游依赖

| 上游模块 | 依赖类型 | 依赖说明 | 依赖成立条件 |
|---------|---------|---------|------------|
| 额度内兑现 | 数据依赖 | 冲销数据来源于额度内兑现记录 | 兑现已审批通过 |
| 出库单 | 数据依赖 | 冲销关联出库单预提数据 | 出库单已生成 |
| 共享财务系统 | 服务依赖 | 冲销结果推送至共享财务系统(ENCX) | 共享财务系统可用 |

### 下游影响

- 影响1：共享财务系统
  - 冲销数据推送至共享财务系统(ENCX)，影响财务核算

- 影响2：额度内余额
  - 冲销后影响额度内余额计算

## 重点逻辑

### 重点逻辑1：冲销数据生成与更新 {数据维护}

- **业务意义**：冲销数据需要定期更新，确保报表数据准确

- **具体逻辑描述**

  - 第1点：通过updateReversalData接口更新冲销数据

  - 第2点：Repository层通过queryWriteoffInQuotaView等方法查询冲销视图数据

  - 第3点：汇总预提、兑现、冲销等数据生成报表

### 重点逻辑2：执行冲销推送 {数据推送}

- **业务意义**：冲销数据推送至共享财务系统，确保财务核算同步

- **具体逻辑描述**

  - 第1点：通过execReversalData接口执行冲销

  - 第2点：推送到共享财务系统(ENCX-额度内冲销)

  - 第3点：单据类型fin_fee_writeoff_in_quota

#### 报错1：冲销数据为空
- **触发条件**：用户按年月/事业部/交易公司查询冲销数据，FIN_FEE_WRITEOFF_IN_QUOTA表返回空结果集
- **逻辑分析**：冲销数据需通过"更新冲销数据"按钮（updateReversalData接口）主动生成，Repository层通过queryWriteoffInQuotaView等方法查询冲销视图数据并写入FIN_FEE_WRITEOFF_IN_QUOTA表。无数据根因有三类：(1)从未执行过更新冲销数据操作，表为空；(2)上游额度内兑现记录未审批通过或出库单预提数据未生成，冲销视图无数据；(3)查询的年月/事业部区间内无冲销记录。需先执行更新冲销数据，再查询确认
- **排查SQL**：
  ```sql
  SELECT IN_WRITEOFF_ID, IN_WRITEOFF_NO, YEARMONTH, ENTNAME, TRADING_COMPANY_NAME,
         BILLING_UNIT_NAME, WRITEOFF_TAX_AMT, WRITEOFF_NOTAX_AMT, WRITEOFF_SUMAMT,
         SYNC_ITEM, BILL_STATUS
  FROM FIN_FEE_WRITEOFF_IN_QUOTA
  WHERE (YEARMONTH = #{yearmonth} OR #{yearmonth} IS NULL)
    AND (ENTID = #{entid} OR #{entid} IS NULL)
  ORDER BY YEARMONTH DESC, IN_WRITEOFF_NO;
  ```

#### 报错2：推送共享财务失败
- **触发条件**：用户选中记录点击"执行冲销"，execReversalData接口推送至ENCX共享财务系统时返回失败
- **逻辑分析**：执行冲销接口执行冲销计算并推送至共享财务系统（ENCX-额度内冲销），单据类型fin_fee_writeoff_in_quota。失败根因有三类：(1)ENCX共享财务系统不可用或网络中断；(2)推送数据异常，如冲销含税/不含税金额为0、法人编码（BILLING_UNIT_CODE）在ENCX中不存在、成本中心编码（COST_CENTER_CODE）不匹配、科目名称（SUBJECT_NAME）未配置；(3)ENCX侧重复推送校验。推送失败需检查SYNC_ITEM和BILL_STATUS字段
- **排查SQL**：
  ```sql
  SELECT IN_WRITEOFF_ID, IN_WRITEOFF_NO, BILLING_UNIT_CODE, COST_CENTER_CODE,
         SUBJECT_NAME, WRITEOFF_TAX_AMT, WRITEOFF_NOTAX_AMT, SYNC_ITEM, BILL_STATUS
  FROM FIN_FEE_WRITEOFF_IN_QUOTA
  WHERE IN_WRITEOFF_ID IN (#{ids}) AND (BILL_STATUS != 1 OR SYNC_ITEM IS NULL);
  ```

#### 报错3：要执行的数据为空
- **触发条件**：用户在执行冲销弹窗中填写年月和交易公司编码后点击确定，queryQuotaLimitHead查询返回null
- **逻辑分析**：execReversalData接口在FinFeeWriteoffInQuotaServiceImpl.java:97处校验data为null时抛出CommonException("要执行的数据为空！")。queryQuotaLimitHead按交易公司编码（TRADING_COMPANY_CODE）和年月（YEARMONTH）查询冲销头数据，返回null表示该交易公司在指定年月无冲销数据。根因有二：(1)未先执行"更新冲销数据"生成冲销记录；(2)交易公司编码与冲销数据不匹配。需先执行更新冲销数据，再执行冲销
- **排查SQL**：
  ```sql
  SELECT IN_WRITEOFF_ID, IN_WRITEOFF_NO, YEARMONTH, TRADING_COMPANY_CODE,
         TRADING_COMPANY_NAME, BILL_STATUS, WRITEOFF_TAX_AMT
  FROM FIN_FEE_WRITEOFF_IN_QUOTA
  WHERE YEARMONTH = #{yearMonth} AND TRADING_COMPANY_CODE = #{tradingCompanyCode};
  ```

#### 报错4：共享接口返回null,执行共享接口失败
- **触发条件**：执行冲销时调用arrowFsscSdk.inLimitBudPush推送共享财务系统，返回FsscRsVO为null
- **逻辑分析**：execReversalData接口在FinFeeWriteoffInQuotaServiceImpl.java:196处校验fsccRsVO为null时抛出CommonException("共享接口返回null,执行共享接口失败！")。该异常表示共享财务系统接口（inLimitBudPush）无响应或网络中断，未返回任何结果对象。根因有三类：(1)ENCX共享财务系统服务不可用；(2)网络连接中断或超时；(3)共享接口URL配置错误。需检查网络连通性和ENCX系统状态
- **排查SQL**：

  ```sql
  SELECT IN_WRITEOFF_ID, IN_WRITEOFF_NO, TRADING_COMPANY_CODE, YEARMONTH,

  ```
