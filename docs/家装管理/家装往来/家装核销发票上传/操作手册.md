# 家装核销发票上传 · 操作手册

> **适用模块：** 家装管理 → 家装往来 → 家装核销发票上传  
> **适用角色：** 经销商、家装业务操作员  
> **前置条件：** 已有家装项目出库记录，且持有交易发票/收据凭证

---

## 一、功能说明

本菜单用于将家装项目出库后的交易发票凭证上传到系统，作为真实性核销的第一手证据。

**核心能力：**

| 能力 | 说明 |
|------|------|
| 发票上传 | 上传发票/收据/非发票等交易凭证 |
| OCR自动识别 | 上传凭证后自动识别发票代码、号码、金额、明细，减少手工录入 |
| 防重复核销 | 同一发票代码+发票号码不得被重复核销，系统自动校验 |
| 审批流转 | 提交后进入OA审批流程，审批通过后发票生效，可供真实性核销引用 |

**业务在全链路中的位置：**

```
项目报备 → 项目合同 → 订单 → 出库 → ★ 核销发票上传（本功能）★
  → 真实性核销 → 抬价返还
```

---

## 二、操作前置条件

| 前置项 | 要求 |
|--------|------|
| 家装项目 | 已完成项目报备，项目状态为有效 |
| 出库记录 | 项目下已有出库明细（发票上传的前置业务） |
| 经销商档案 | 当前登录用户已关联有效的经销商编码 |
| 权限 | 拥有"家装核销发票上传"菜单访问权限 |

## 三、操作步骤

### 3.1 进入列表页

1. 登录系统，在左侧菜单栏点击 **家装管理 → 家装往来 → 家装核销发票上传**
2. 进入列表页，默认不自动查询数据

### 3.2 查询核销发票

在列表页查询栏中，可按以下条件筛选：

| 查询条件 | 说明 |
|---------|------|
| 审批状态 | 下拉选择：新建/审批中/审批通过/审批拒绝等 |
| 核销单号 | 输入完整单号精确查询 |
| 发票上传日期 | 选择日期范围 |
| 项目编码 / 项目名称 | 按项目筛选 |
| 经销商编码 / 经销商名称 | 按经销商筛选 |
| 验真通过 / 二次验真通过 | 筛选是否通过验真 |
| 申请人 / 修改人 | 按操作人筛选 |
| 修改时间 | 选择修改时间范围 |

点击 **查询** 按钮执行筛选，双击某行可进入详情页查看。

### 3.3 新建核销发票上传单

#### 步骤1：点击新建

在列表页点击 **新建** 按钮，进入详情页新建态。

#### 步骤2：填写基础信息

| 字段 | 是否必填 | 填写说明 |
|------|---------|---------|
| 核销单号 | — | 保存后系统自动生成，不可编辑 |
| 发票上传日期 | — | 系统自动赋值为当前日期 |
| 申请人 | — | 系统自动填充当前登录用户姓名 |
| 单据状态 | — | 默认"新建"，不可编辑 |
| 核销类型 | **必填** | 下拉选择，变更时清空关联字段 |
| 项目编码 | 条件必填 | 核销类型为"家装项目"时必选，通过弹窗选择家装项目 |
| 经销商编码 | 条件必填 | 核销类型为"家装项目"或"收据"时必选，通过弹窗选择经销商 |
| 交易公司 | 条件必填 | 选择经销商后可选，通过弹窗选择交易公司 |
| 开票单位 | — | 由交易公司自动带出，不可编辑 |
| 备注 | 选填 | 可输入备注信息 |

#### 步骤3：维护发票影像信息

在 **发票影像信息** 区域：

1. 点击 **新建（发票影像行）** 新增一行
2. 系统自动生成凭证号码
3. 选择 **凭证类型**（必填）：
   - **非发票** — 不触发OCR识别
   - **发票** — 上传附件后自动触发OCR识别
   - **收据** — 上传附件后自动触发OCR识别
4. 上传 **凭证附件**（必填）：支持图片/PDF格式
5. （可选）上传 **清单附件**：仅支持PDF和JPG格式
6. 填写 **备注**（可选）

> **OCR提示：** 凭证类型为"发票"或"收据"时，上传附件后系统自动调用OCR识别接口，识别成功后自动填充发票主要信息和详细信息。OCR识别失败时可点击"重新识别"。

#### 步骤4：维护发票主要信息

在 **发票主要信息** 区域：

1. 点击 **新建（主要信息行）** 新增一行
2. 填写以下字段：

| 字段 | 是否必填 | 填写说明 |
|------|---------|---------|
| 凭证号码 | **必填** | 下拉选择，来自发票影像行的凭证号码 |
| 发票代码 | **必填** | 输入发票代码，修改时触发重复校验 |
| 发票号码 | **必填** | 输入发票号码，修改时触发重复校验 |
| 开票日期 | 选填 | 选择开票日期 |
| 购买方名称 | 选填 | 输入购买方名称 |
| 销售方名称 | 选填 | 输入销售方名称 |
| 购买方联系电话 | 选填 | 输入联系电话 |
| 楼号 | 选填 | 输入楼号 |
| 总额 | 选填 | 输入发票金额（不含税额），精度2位 |

#### 步骤5：维护发票详细信息

在 **发票详细信息** 区域：

1. 点击 **新建（详细信息行）** 新增一行，或点击 **明细导入** 批量导入
2. 填写以下字段：

| 字段 | 是否必填 | 填写说明 |
|------|---------|---------|
| 凭证号码 | **必填** | 下拉选择，来自发票影像行 |
| 发票代码 | 选填 | 输入发票代码 |
| 发票号码 | **必填** | 输入发票号码 |
| 产品名称 | 选填 | 输入货物或服务名称 |
| 产品编码 | 选填 | 输入产品编码 |
| 规格型号 | **必填** | 输入规格型号，修改时自动匹配基本单位 |
| 发票数量 | **必填** | 输入发票上的数量，最小值0 |
| 转换率 | **必填** | 发票数量到基本单位的转换率，精度5位，最小值0 |
| 基本单位 | **必填** | 通过弹窗选择基本计量单位 |
| 发票单位 | 选填 | 输入发票上的计量单位 |
| 单价 | **必填** | 输入产品单价，最小值0 |
| 金额 | 选填 | 输入金额，精度2位 |
| 税率(%) | 选填 | 输入税率，范围0-100 |
| 税额 | 选填 | 自动计算 = 金额 × 税率 / 100 |

> **批量导入：** 可点击"模板下载"获取导入模板，按模板填写后点击"明细导入"批量上传。

#### 步骤6：保存

点击 **保存** 按钮，系统自动校验以下内容，任一校验失败将阻断保存：

| 校验项 | 校验内容 | 失败提示 |
|--------|---------|---------|
| 基本单位 | 详细信息每行基本单位不能为空 | "明细行基本单位不能为空！" |
| 头信息一致 | 详细信息的凭证号码+发票代码+发票号码须在主要信息中存在 | "明细第X行，未存在头信息，请检查！" |
| 转换率有效 | 详细信息转换率不能为空或≤0 | "发票详细信息中第X行转换率不能为0" |
| 发票不重复 | 同一核销单内发票代码+发票号码不得重复 | "发票代码-发票号码(xxx-xxx)已在第X行存在" |
| 跨单不重复 | 发票代码+发票号码不得被其他核销单使用 | "xxx已被其它单进行核销" |

校验通过后，核销单号自动生成，单据状态为"新建"。

#### 步骤7：提交审批

确认信息无误后，点击 **保存并提交** 按钮，系统将：

1. 执行保存校验（同上）
2. 执行提交校验：
   - 非发票类型主要信息只能存在一行
   - 发票类型的主要信息须有完整的发票号码和发票代码
   - 详细信息转换率不能为0
   - 详细信息行金额（单价×数量）须与主要信息总额一致（允许0.01元差异）
   - 发票主要信息和详细信息不能为空
3. 校验通过后推送OA审批流程
4. 单据状态变更为"审批中"

## 四、状态说明与可执行操作

| 状态 | 说明 | 可执行操作 |
|------|------|-----------|
| 新建 | 刚创建或保存后的状态 | 编辑、保存、删除、保存并提交 |
| 审批中 | 已提交审批，等待审核 | 查看（不可编辑/删除） |
| 审批通过 | 审批已通过，发票生效 | 查看 |
| 审批拒绝 | 审批被拒绝 | 编辑、保存、删除、修改后重新提交 |
| 已撤回 | 审批中被撤回 | 编辑、保存、删除、修改后重新提交 |
| 终止 | 流程被终止 | 查看、撤销终止 |
| 挂起 | 流程挂起 | 查看 |
| 退回 | 流程退回 | 查看 |

**状态流转图：**

```
新建 ──保存并提交──→ 审批中 ──审批通过──→ 审批通过
                        │
                        ├──审批拒绝──→ 审批拒绝 ──重新提交──→ 审批中
                        ├──撤回──→ 已撤回 ──重新提交──→ 审批中
                        └──终止──→ 终止
```

## 五、其他操作

### 5.1 导出

在列表页点击 **导出** 按钮，系统按当前查询条件异步导出Excel，默认全选。

### 5.2 删除

在列表页选中某行，点击 **删除** 按钮。

**可删除状态：** 新建、审批拒绝、已撤回、终止  
**不可删除状态：** 审批中、审批通过、挂起、退回

### 5.3 查看详情

在列表页双击某行或点击 **查看** 按钮，进入详情页查看模式。

## 七、常见问题

### Q1：OCR识别后发票信息未自动填充？

**可能原因：**
- 凭证类型为"非发票"，不会触发OCR识别
- 发票图片不清晰或格式不支持
- 附件上传失败

**处理步骤：**
1. 确认凭证类型是否为"发票"或"收据"
2. 检查发票图片是否清晰完整
3. 若OCR识别失败，点击"重新识别"按钮重试
4. 若仍失败，尝试重新上传附件

### Q2：保存时提示"xxx已被其它单进行核销"？

**可能原因：** 该发票代码+发票号码已存在于其他核销单中。

**处理步骤：**
1. 在列表页查询该发票号码，确认是否已上传过
2. 若为误操作重复上传，删除其中一张即可
3. 若确实需要重新核销，需先在原核销单中作废该发票

### Q3：提交审批时提示"金额不一致"？

**可能原因：** 详细信息行的单价×数量汇总与主要信息的总额不匹配。

**处理步骤：**
1. 检查详细信息每行的单价和数量是否正确
2. 确认主要信息的总额与详细信息汇总一致
3. 系统允许0.01元的差异

### Q4：列表页查询不到数据？

**可能原因：**
- 当前用户没有对应的家装核销发票上传数据
- 查询条件过于狭窄

**处理步骤：**
1. 清空所有查询条件，点击查询查看全量数据
2. 确认当前登录账号是否有家装业务数据权限
3. 联系系统管理员确认数据权限分配

### Q5：无法删除核销单？

**可能原因：** 审批状态为审批中/审批通过/挂起/退回时不可删除。

**处理步骤：**
1. 查看该单据的审批状态
2. 若为审批中，需先撤回或等待审批完成后再处理
3. 若为审批通过，需走作废流程而非删除

### Q6：转换率默认值是什么？

**说明：** 大部分组织下，新建详细信息行转换率默认为1。个别特殊组织需手工填写转换率。

## 八、注意事项

1. **发票唯一性：** 同一发票代码+发票号码在系统中不能重复核销，保存前系统会自动校验。
2. **OCR依赖：** OCR识别依赖发票图片质量和清晰度，请确保发票完整可见。
3. **金额一致性：** 提交审批时系统会校验详细信息行金额与主要信息总额是否一致。
4. **审批状态控制：** 审批中/审批通过/挂起/退回状态下不可编辑和删除。
5. **导入前准备：** 明细导入前必须先维护发票影像信息，导入模板字段需完整填写。
6. **凭证号码自动生成：** 新建发票影像行时系统自动生成凭证号码，不可手工修改。
